# 录入判准

**本档不是格式，是录入判准**：讲一条记录该不该建、该挂在哪里、几条该不该并、时代朝代怎么判。字段的形状、必填、枚举、规范名表都不在这里——格式见 [common.md](common.md)、[work.md](work.md)、[book.md](book.md)；整理本、辑佚档见 [text-files.md](text-files.md)。录入时与格式同读。

本档各条皆自实测而来，例子、数字照录（截至各条定下之日）。说明文字用简体；书名、引文、id、字段值照数据原文（多为繁体）。

| 节 | 讲什么 |
|---|---|
| 一 | 原典与注本：分层与系连 |
| 二 | 一条 Work 记录代表什么 |
| 三 | 同题二条，何时是重出、何时是二书 |
| 四 | 版本附属部帙：不新建 Work |
| 五 | 「別本」之节：与正条共系一 Work |
| 六 | 时代与朝代的判法（`period`、`period_upper`、`authenticity`、`loss_status`、`dynasty`） |

## 一、原典与注本：分层与系连

一部经有几百家注。注本**各自成 Work**，以关联词系于原典，不并入原典条。

### 规则

> `authors[0].role` 为**注、傳、疏、箋、章句、集解、義疏、音義、注疏、集注、
> 補注、校注、正義、疏證、集釋**之属者，该 Work 是**注本**，
> 必系 `contains_text_of` 至其原典 Work（写在注本一侧）；原典侧之 `text_carried_by` 由 build 生成，**原典源档不写**。

**题名**从其志书原题，**唯与原典之题完全同字时**须冠注者名以别之
（《古文尚書》鄭玄注 → 题《古文尚書鄭玄注》）。
题中已有体裁字样者（《周禮注疏》《春秋穀梁傳集解》）**不必再冠注者名**，冠之反而累赘。

### 何以不并入原典

本库已有五十五个原典锚，运转良好：

| 原典 | 系其下之注本 |
|---|---:|
| 周易 `1evl7l48e27ls` | 1,041 |
| 偽古文尚書 `1evd3dbcb0nb4` | 386 |
| 論語 `1ev7w0euvaeww` ／ 詩經 `1evl7hsxvr7cw` | 各 379 |
| 孝經 `1evl1xugdoikg` | 300 |
| 左傳 · 漢書 · 禮記 · 周禮 · 儀禮 · 孟子 · 公羊傳…… | 252～93 |

并入即是把一千零四十一部书压成一条，磁铁之极致。

### 一个容易误判的形态

`authors[0].role` 是「傳」而题名不含其人名者，**未必是注本误题**——
《左傳》`1ev7vo50ar94w` 的 `authors[0]` 是「左丘明·傳」，那是原典本身的体裁
（左丘明传《春秋》），不是「左丘明注左传」。**改题之前先看它是不是锚。**

### 坊刻编本（纂图互注之属）是独立 Work，不是原典的版本

判准只有一条：**成书之结构与内容与原书不一致者，即是一个新的 Work**——
加了注释是新书（周易鄭玄注不是周易），所加之注即使只是抄他经之语（「互注」）也是
注释；加图表（「纂圖」）、加标记层（「重言」「重意」）、汇数家之注而新编门目，皆同。
新 Work 与原典以 `contains_text_of` 相系。

实例：南宋建阳坊刻《纂圖互注毛詩》——卷首举要图二十五幅、正文全录大小序及毛传
郑笺释文、采左传三礼为互注、标重言重意（陸元輔：「唐宋人帖括之書」）——结构全非
《毛詩》之旧，是独立 Work。《纂圖互注揚子法言》《新纂門目五臣音注揚子法言》同。

连带三则：**(1)** 此类编本之 `authors` 不系原典撰人（扬雄不是纂图互注本的编者；
编者不详即空），**(2)** `period` 从成编之世（坊刻多宋），不从原典撰人之代，
**(3)** 其所挂 Book 须清点——普通原典刊本误堆于编本条下者，移系原典（或注本）条。

## 二、一条 Work 记录代表什么

### 先建 Work、后补 Book 是正常次序

一部书先有作品记录、日后再补实物记录，这是本库的正常工作次序，不是缺陷。

**Work 之来源为版本目录者（國立故宮博物院善本舊籍、續修四庫全書、
四庫全書存目叢書、中華再造善本之属），仍是作品记录，不因来源而降格。**
实测此类 15,185 条中，**12,272 条（81%）是库中该书的唯一记录**——
若因其来源是版本目录就视为「版本条」，等于把八成正当的作品记录判成杂质。

### 一部书、数部藏本 → 一个 Work、数个 Book

同一部书在同一部版本目录中有数部藏本者，应为**一个 Work、数个 Book**，
不是数个 Work。

### 缺字订正之后必须回头查同题

汇入时题名带缺字者，**彼此比对不上，去重会漏**。库中实例：
《訒庵集古印存》与《恆軒所見所藏吉金錄》各有二条，同出故宫善本目录，
一条首字作 U+FFFD 替换符、一条作私用区 PUA 字符，故汇入时「无同名 Work」而各建一条；
分两次订正缺字之后题名才相同，重出方才暴露。

**故：订正缺字之后，须以新题回查全库同题，不可订完就算。**

## 三、同题二条，何时是重出、何时是二书

同题而疑重出者，判之之法**不在题名，在著录**。以下各条皆自 size=2 同题组
七百六十九次合并与千余次不并之实测所得，逐条可验。

### 1. 卷数之异：同志则疑，异志则不疑

| 情形 | 判 |
|---|---|
| 二条同出**一志**而各有全著录语、卷数复异 | **疑二书**——是该志之两著录 |
| 二条分见**二志**而卷数异 | **不作二书之证**——各志所据之本不同，卷数本多歧 |

《褚仲都講疏》十卷／十六卷同出新唐志，是二书；《地理書》陸澄一百五十卷
（国史）与一百四十九卷（隋志）则是一书。**此二者方向相反，不可混用。**

**又有一种卷数之异全非二书之迹**：并者所取乃附录／别集之卷数。四库作
「《文正集》二十卷、《別集》四卷、《補編》五卷」，遂切出《范文正集》二十卷
与四卷两条；《顏魯公集》十五卷／《補遺》一卷、《乖崖集》十二卷／《附錄》一卷
皆同。**此类卷数异反是同一著录条被切两次之迹**——且附录别集依
〈四、版本附属部帙〉本不当另立 Work。

### 2. 裸系一源而无著录语者，多是重出

一侧仅系一志而 `indexed_by[].title_info` 为空，而该志之全著录语另一侧已有
——是同一著录条被切两次。此型于直斋书录解题尤多。

### 3. 志书之「又」例：同题而别是一书

《舊唐書經籍志》作「《春秋左氏傳例》七卷。**又十五卷，杜預撰。**」
——「又」是志书之例，谓同题而别是一书（别本或他家所撰），**非重出**。

### 4. 《漢志》一名分列二略者是二书

《漢志》同一书名分见诸子略与兵书略者，部类异、篇数亦异，是二书：

| 书 | 诸子略 | 兵书略 |
|---|---|---|
| 師曠 | 小説 六篇 | 隂陽 八篇 |
| 力牧 | 道 二十二篇 | 隂陽 十五篇 |
| 龐煖 | 從横 二篇 | 兵權謀 三篇 |
| 五子胥 | 雜 八篇 | 兵技巧 十篇 |
| 李子 | 法家 三十二篇 | 兵權謀 十篇 |

### 5. 出土简帛与后世同名之书，只是题名巧合

**并之则两事俱毁。** 马王堆帛书《易傳》之〈繫辭〉× 元保八《繫辭》二卷；
阜阳汉简《大事記》（竹简编年记事，起西周迄汉初）× 宋呂祖謙《大事記》
二十六卷；出土《脈法》× 元黃大明《脈法》三卷；睡虎地《日書》×
国史经籍志譚融《日書》三卷。

判别之法：其 `description.sources` 或 `ai_note` 载出土整理报告者即是。

### 6. 一方无撰人者，先问其 role

一方有撰人而一方无者，**存者之 role 若为注／传／疏／集解，则无撰人之一方
疑即原典**——《歸藏》（无撰人）与《歸藏薛貞注》（薛貞）是原典与注本之别，
注家有其创作，本为二物，**绝不可并**。role 为撰／编／辑者方可依上列各条续判。

### 7. 撰人异名之辨：看两名在库中之分量

撰人名一字之差者，混着真异人与形讹，且真异人多是名家——蘇軾／蘇洵／蘇轍、
陸雲／陸機、曹操／曹丕、阮福／阮元、劉熙／劉珍、毛萇／毛亨、吳鼒／吳鼐。

**分之之法：讹字之名于全库不系任何作品，正名则系十数部。** 以「弱名系 0 部
且强名系 ≥5 部」为准方可断为形讹（朱喜→朱熹、呂楠→呂柟、戴雲→戴震、
王誾運→王闓運、李容→李顒、劉嚴→劉表）。分量相当者一律不并。

**名相含亦未必一人**：《棋品序》陸雲（晋，系八部）× 陸云公（南朝梁）。

### 8. 比对书名之前必先简繁归一

以严格相等比对著录语所题之书名，实测挡下三十九组，逐一看去**三十八组是
假阳性**——异体（龜鑑／龜鑒、寶／寳、歷／歴、略／畧、鉅／钜、祕／秘、
羣／群、決／决）与连书省撰人式著录（「曾肇曲阜集」对《曲阜集》）。
须以 OpenCC 归一、补异体表、剥去「梁有」「欽定」等冠首语，方余真异者。

**且不可用子串比对**：《新刻出像增補搜神記》因「搜神記」是其子串而被放行，
而该条实混装——题名为明增补本，所系隋志、旧唐志之著录语却作《搜神記》三十卷。

### 9. 合并之际：存者可依源数而取，撰人之名须另判

存者依 `indexed_by` 源多者而取，是常法。**然讹名那一侧之著录源可能反多**
——实测十组形讹中有四组如此，遂使《荊州占》存「劉嚴」而非「劉表」、
《二曲集》存「李容」而非「李顒」。

**故取存者之后，须另判其撰人之名孰正**，讹形入 `alt_names`。
此误之迹见于 `chk.py`「人物→作品 单向」上升——正名之 Entity 所 claim 之书落了空。

### 10. 合并之后必须同步者

- `index/works/*.json`（title／path／author／role／dynasty／period／juan_count…）
- **`index/books/*.json` 之 `work_id`**——Book 改指而此处未同步，
  `chk.py`「索引栏位不符」即现
- ~~Entity `works[]`~~：schema-v2 起 Entity 不存作品列表，改 `authors[].entity_id` 即足；**但撰人之名孰正须另判**（见上条）
- 随迁之 `fragments/*.json`：其**档内 `work_id` 须随路径改**，
  且存者之 `ai_note` 须记其档位（`chk.py` 以 ai_note 含 `fragments/` 为据）
- 随迁之 `collated_edition/*.json`：只做精准字符串替换，不整档重写
- **被并者在分类类档里的成员行**（`classification/<分类法>/members/`）：改为存者之 id 或删去（存者已有归属时），经 `bim classify`，不手改
- 他条指向被并者之引用，只改**存储一侧**的字段：`Book.work_id`、`contained_in[].id`、`authors[].entity_id`、规范方向之 `related_works[].id`、`indexed_by[].source_bid`、`Collection.work_id`／`contained_in`；反向与展示副本由 build 重生，不必改
- `index/` 由 build 重生（并入前仍跑 `reindex.py`）

> 注：整理本、辑佚档今已不在本仓，在 book-text 仓（见 [text-files.md](text-files.md)）；上列两条「随迁之…」的动作要在 book-text 里做。

来历：2026-08-22 定。

## 四、版本附属部帙：不新建 Work

书目书（直斋书录解题、四库总目之类）著录一部集子时，往往在同一条解题下
连记数事：《昌黎集》四十卷、《外集》十卷、《附錄》五卷、《年譜》一卷、
《舉正》十卷……汇入时每事各成一节（section），节题只作《外集》《附錄》，
不成书名。这些节该不该各建一个 Work？**分两类，判准是「是不是同一本书」，
不是看书名。**

### 甲、该版本之附属部帙 —— 不新建 Work

**外集、别集、后集、续集、续编、续稿、内外制集、附录、目录、序、杂记、
附益、图** 之属，凡与正集**一同刊印、随本而存**者：

- 书目书说的是「**某某本**所包含者」——即使分册，也是一起印出来的一部书。
- 这些部帙**历史上从不被视为单独的书**，也没有哪个版本单独印一部《附錄》
  或《外集》行世。
- 故它们是**该版本之附属部分**，其信息挂在该版本的 **Book** 上，
  记入 `Book.attached_texts[]`（「随本附刻之序跋、附录等」，库中已用 303 条，
  如《古音叢目》附刻《古音獵要》《古音餘》《古音附錄》），
  **不新建 Work**。

**推论**：`part_of` 只用于**确系同一本书之内**的部分（篇章之于书，如
《繫辭》`part_of`《周易》、《緇衣》`part_of`《禮記》）。书名里有「別集」
「外集」「續編」二字，不等于它是另一本书，也不等于它是本书之一篇——
**先问是不是同一本书，再定关系词**。

### 乙、他人所撰之研究著作 —— 新建 Work，走 `studies`

**年谱、举正、音义、考异、指要、备要、本义、通例、补注** 之属，凡**出于
他人之手、可单行**者：

- 直斋韩集条下之《年譜》是**洪興祖**撰、《舉正》是**方崧卿**撰；柳集条下之
  《音釋》《摭異》是**葛嶠**裒集——皆非韩柳自己的文字。
- 说它们 `part_of`《昌黎集》语义即错：它们不是韩愈集子的一部分，
  是**研究韩集的另一部书**，只是恰好与韩集同刻。
- 故**新建 Work**，在研究著作一侧写 `studies` 系之（被研究者一侧之 `studied_by` 由 build 生成）
  （库中既有：《史記音義》`studies`《史記》、《何超晉書音義》`studies`《晉書》，音义类 41/42 皆如此）。

### 判别之问

| 问 | 甲（附属部帙） | 乙（研究著作） |
|---|---|---|
| 出于谁手？ | 本集作者，或编者所辑本集之遗文 | **他人**所撰 |
| 曾否单行？ | 从未单独刊行 | 可单行（方崧卿《韓集舉正》四库别有著录） |
| 落在哪里？ | `Book.attached_texts[]` | 新 Work ＋ `studies` |

**两可者**（如《目錄》：司馬光《通鑑目錄》三十卷四库别出著录，是乙；
《政和五禮新儀目錄》随本而存，是甲）——**以「曾否单行」为断**，
不能断者记 `ai_note` 存疑，不强分。

来历：2026-08-21 定。

## 五、「別本」之节：与正条共系一 Work

《欽定四庫全書總目》著录一书之后，每别出一条作「**別本某某**」——
《別本公是集》六卷之于《公是集》五十四卷、《別本農政全書》四十六卷之于
《農政全書》六十卷、《別本讀書蕞殘》二卷之于《讀書蕞殘》三卷……
其提要多自言「與前一本大同小異」。

**别本是同一部书之另一传本，不是另一部书。** 依本库通则
（版本之异落在 Book，不落在 Work），别本之节当**与正条共系同一 Work**，
不新建。

### 故其节标 `section_kind: "別本"`

共系既是对的，`chk.py`〈整理本 section 级磁铁〉便不当计之——
该验本为捉「汇入时同名条目未分」而设，别本之共系是**裁定之果**，非未分之遗。
标此栏，chk 比照 `附屬部帙` 别计而不入磁铁之数。

| `section_kind` | 何谓 | chk 之待遇 |
|---|---|---|
| `附屬部帙` | 该版本随本而存之外集、附录之属（见〈四〉甲类） | 别计，不入磁铁 |
| `別本` | 同书之另一传本，书目别出一条者 | 别计，不入磁铁 |
| `一書兩著` | **同一书目之中，一书两出其目**——题同而卷数异，或题异而同指。书目自身之重出，非本库汇入之失 | 别计，不入磁铁 |

（`section_kind` 是整理本 section 上的字段，整理本今在 book-text，见 [text-files.md](text-files.md)。）

**认法**：四库之节题首二字即「別本」，机械可认；然**仍须读其提要**——
提要言「大同小異」「即前本而多某卷」者是别本，言「別為一時之作」
「節錄本」者不是（此准同姚振宗《隋書經籍志考證》之例，见 N2 道所立）。

来历：2026-08-24 定。

### `一書兩著`：书目自身之重出

原记「不及者二」——同题而卷数异之「一书两著」、二节之题确异而同指一书者，
各余九十、一百八题，皆已逐条裁为正当共系**而无栏可记**——今补此栏，二者同用之。

**何以合为一栏**：二者之别只在题面（一题同卷异，一题亦异），
而其实同是一事：**书目自己把一部书著录了两次**。焦竑《國史經籍志》多取前志
成文，同书两见尤多（《齊典》五卷／四卷俱题王逸、《朝制要覽》五十卷／十五卷
俱题宋咸、《唐錄政要》十二卷／十三卷俱题凌璠）；姚振宗《隋書經籍志考證》
则每自言之（引錢大昕「一書而兩出」、章宗源「當系重出」）。
既是书目之重出，本库以一 Work 承之而诸节共系，正是对的。

**标法**：一组之中**留其书目次第在先者不标**（是为正著），其后重出者标之。
如此该 work 在该书目中只余一未标之题，磁铁自消，而重出之事仍见于各节。

**须逐条裁，不得以「同题」机械施之**——同一书目两见同题而**撰人异**者，
多是二书非一书（《黃庭內景經》梁丘子注与唐自履忠注即其例，二注本各为一书）。
标此栏前须读其著录语之撰人与案语。

来历：2026-08-24 补。

### 附记：书目书所述之版本，库中未必有 Book

直斋著录之诸本（韩集之李漢序本、方崧卿南安軍本、朱熹校定本；柳集之三本）
**库中皆无对应 Book 记录**（`Book.indexed_by` 现无直斋一源）。
故施行〈四〉甲类之法前，须先定：是为这些版本各建 Book，
还是暂记于母 Work 之该条 `indexed_by[]` 著录内。**此事未决前不得批量施行。**

来历：2026-08-24 定（附记随〈四〉2026-08-21 所定）。

## 六、时代与朝代的判法

字段（`period`、`period_basis`、`period_upper`、`period_upper_basis`、`dynasty`、`dynasty_basis`、`authenticity`、`authenticity_basis`、`loss_status`）的格式、枚举与规范朝代名全表见 [common.md〈朝代与时代轴〉](common.md) 与 [work.md](work.md)。本节只讲怎么判。

### 6.1 `period`：为何另立一轴

**与 `authors[].dynasty` 分立，不取代之。** `dynasty` 是志书原文（「魏」「宋」「漢」），
改之则失其所本；`period` 是本库之判，粗粒度而**无歧义**，供选集合之用。
判之所据记于 `period_basis`，逐条可读。

立此轴之由：库中 `dynasty` 有八十八种写法，且歧义是实质的——
魏（曹魏／北魏）、宋（劉宋／趙宋）、周（先秦／北周／後周）、齊（南齊／北齊）、漢（西／東）。
不立此轴，「哪些是秦汉的」都选不出来。

来历：2026-08-06 定。

### 6.2 `period` 不是 `dynasty` 的函数，也不该是

`dynasty → period` 实测七十七种写法中六十三种单射，然十四种一对多。
其中三类是**正当的**，正是本轴立此之由：

| 类 | 例 | 何以不同于 dynasty |
|---|---|---|
| 舊題撰人 ≠ 实际撰人 | 《西京雜記》`1ev3bcikfdiww` authors[0]「劉歆·漢·舊題撰」，authors[1] 方是「葛洪·東晉·撰」 | 判 `jin`。机械取 authors[0] 则误作 `qin-han` |
| 跨代人物 | 《兵書接要別本》`1evfhd9qronpc` 撰人曹操 dynasty「東漢」（生年一五五确在东汉） | 其著作归 `three-kingdoms` |
| 伪托作品 | 《關尹子》托名尹喜（先秦），实宋人作 | 应判 `song`。**此类尚未处理**，待 `authenticity` 栏 |

**故 `period_basis` 须逐条可读**——判与 dynasty 相异者，其由必记于此。

来历：2026-08-06 定。

### 6.3 `period` 判准三重（皆可自验）

1. **粗粒度自消歧**：漢（西／東）皆 `qin-han`、齊（南／北）皆 `nanbeichao`——不必再问。
2. **著录之志为时代上限**（`period_basis: catalog_bound`）：一书见于某志，其时代不得晚于该志。
   此是硬界非推论——《隋書經籍志》成于唐初，赵宋之书无由入之，故「宋」而见于隋志者必刘宋。
3. **断代志可径定**（`period_basis: duandai`）：撰人朝代阙而所著录之志唯一且为断代志者。
   何者断代**以库中资料自验**（看其所著录之书撰人朝代之分布）：
   明史藝文志 明 98%、清史稿藝文志 清 94%、補晉書藝文志 晉 96%、後漢藝文志 98%、
   三國藝文志 93%、元史藝文志与補遼金元 96%。
   **而宋史藝文志宋仅 51%（唐 18%、汉 6%），是通代非断代**——初版误列，
   一举要把八千三百余条判为 song，此验拦下。

   **例外：《清史稿·藝文志》之「輯佚」类目不入断代之列**（2026-08-21 增）。
   该志各部类下有「輯佚」子目，著录清人所辑之本——**其原书可极古**：
   《王粲英雄記》（东汉）、《張璠後漢記》（西晋）、《薛瑩後漢書》（三国吴）、
   《王肅國語章句》（三国魏）、《九家舊晉書》《倉頡篇續》《鄭記》之属皆在焉。
   清史稿之 94% 断代率是就全志而言，于此子目不成立。

   判别之法：条目之 `ai_note` 载「清史稿藝文志〈某部某類〉輯佚條目」者即是。
   实测本例外拦下 **105 条**——皆唯系清史稿一志（duandai 之「志唯一」前提成立），
   而书实非清人所作，原判 qing 无据，已撤（见 `known-issues/duandai清史稿漏洞待覈.json`）。

   **并须以 catalog_bound 复验**：所定之值不得晚于本条所系他志之上限。
   实测另拦下 14 条跨志相斥者（如《晉中興書》唯以清史稿判 qing，而其书见于隋志）。

判不出者留空并出清单（`known-issues/period未決.json`），**不猜**。

来历：2026-08-06 定；清史稿「輯佚」例外 2026-08-21 增。

### 6.4 以撰人之代定书之代者，须记撰人之代出自何处

「书之代取自人、人之代又取自书」会成闭环：entity 之 `dynasty` 本是从其名下某书推出来的，
那书的 `period` 又据「撰人已定代 X」回填，两边互为证而其实都没有证（李淑一案）。

**凡以「撰人已定代 X」为 `period_basis` 者，须同时写明该 entity 之 `dynasty` 从哪里来**
——CBDB／史传／著录／推定四者之一，如「撰人已定代明（其 dynasty 据 CBDB）」。
记了，闭环就自己显形；不另立机检。只治此后之新判，已有者不回头补。

来历：2026-09-24 用户定。

### 6.5 `period_upper`：怎么判上限

**只给上限，不给下限。** 早期志书亡佚极多，一部汉代之书可能迟至《宋史·藝文志》方首见著录——
故「首次著录之志」**不可**当下限用。此点须守死，否则易误用成「见于宋志即宋书」。

**不设 `period_lower`。**

#### 题中年号可为下限

上文所戒者，是拿「首次著录之志」当下限；
书题自身所含之年号则不然——年号者，其事已行而后可名，故题含「熙寧」「開元」者，
其书必不早于该号之元年。此证出于书题，与著录先后无涉，不犯上戒。

其用在**与上限相夹**：下限与 `period_upper` 同落一代者，其代即定，直接写入 `period`，
不另立字段（故仍「不设 `period_lower`」）。如《熙寧葬式》，题中「熙寧」元年 1068 落在
`song`，而其上限亦 `song`，上下既合，代乃定。实测全库得 317 条。

**施之须防三误**，皆已见于实测：

| 误 | 例 | 防法 |
|---|---|---|
| 年号字面本是常语 | 《太極真人九轉還丹經》之「太極」乃道家之名，非睿宗年号；又「天啟」「元貞」「正德」「同光」「元符」皆可作常语 | 立**排除字表**，凡可作常语者不取 |
| 年号同名分属两代 | 「太和」「建元」「永平」「甘露」「黃龍」之属，一名数代 | 同名数代者一概不取（`AMBIG`） |
| 子串偶合 | 《崇天曆》《明天曆》《應天曆》皆宋历，而字面含元之「天曆」；《大中統類》含「中統」；《賈躭唐七聖曆》含「聖曆」 | 凡**下限晚于上限**者一律弃之——实测 32 条相斥，逐一验之，无一真相斥，尽是子串偶合。此即以上限为筛，自去其伪 |

来历：2026-08-24 增。

#### 只标于 `period` 为空或存疑者，不全库标

`period` 已定而无疑者标之徒增冗余：

| 情形 | 处置 |
|---|---|
| `period` 有值，且 ≤ 其著录志之上限 | **不标**——上限是冗余 |
| `period` 有值，而 > 其著录志之上限 | **相斥即错**，先查错，不标 |
| `period` 为空 | **标**——此时上限是唯一可筛之轴 |

实测（2026-08-21 末）：`period` 为空者 32669 条，其中 30188 条（92.4%）可得上限，2481 条无据。再补出土、子目、描述版本、丛编、歧义朝代五源后，上限覆盖 31613 条（96.8%），余 1054 条全无线索——故宫善本旧籍只记「鈔本」而无年者 706、无描述无著录之空白条 243、有描述而不涉年代者 104、朝鲜 1。此 1054 条无 contained_in 可传递（实测可传递者 0），暂无他法。

#### catalog_bound 作消歧几乎无用

〈6.3〉判准二举「『宋』而见于隋志者必刘宋」为例，
实测全库待消歧之 899 条（宋 842、周 41、蜀 13、魏 3）中仅 **3 条**可解——
歧义写法之条目多出自宋志、国史经籍志、四库，其志上限本已 ≥ song，分不开。
catalog_bound 之真价值在**验证**（实测查出 437 条 `period` 逾限）与**上限标注**，不在消歧。

#### 陷阱：清代志书之「輯佚」类目

《清史稿·藝文志》各部类下有「輯佚」子目，
《四庫全書總目》《經義考》《書目答問》亦大量著录清人之辑本、注本、校本——
**其所指原书可以极古**。故：

- 不得因见于清代志书即判 `qing`
- 判准三（断代志）以清史稿为 94% 断代，**有此漏洞**，据之所定者须复核
- 实测 `period=qing` 而逾限之 108 条，其所系：清史稿 73、四库总目 35、经义考 17、书目答问 15

#### 上限之六源

`period_upper` 不限于著录志，凡可证「其时已有此书」者皆可为上限
（`scripts/period_bounds.py`，取诸源中最紧者）：

| 源 | 判语 | 例 | 实测 |
|---|---|---|---|
| `catalog_bound` | 一书见于某志，其时代不得晚于该志 | 见《直齋書錄解題》→ ≤ song | 28739 |
| `edition_bound` | 版本之年不早于成书之年 | 有「明嘉靖四十一年太醫院刊本」→ ≤ ming | 1021 |
| `excavation_bound` | 简帛抄写之年不早于成书之年 | 出清华战国楚简 → ≤ pre-qin | 19 |
| 志书子目断代 | 目录之类目自言其代者，即断代之判 | 孫楷第《中國通俗小說書目》「宋元部」→ ≤ liao-jin-yuan | 686 |
| `collection_bound` | 丛编自限所收之代者，其代即上限 | 收入《續修四庫全書》→ ≤ qing | 548 |
| 歧义朝代取最晚解 | 消歧不成，上限犹可得 | 撰人作「宋」（劉宋｜趙宋）→ ≤ song | 600 |

#### 五事须守

1. **`edition_bound` 不可机械取。** 《周禮》有宋刊本而自是先秦典籍——上限止是上限，
   `period` 已定而不相斥者不动。相斥之判用**年份区间**（`PERIOD_YEARS`）而非 `ORD` 之序：
   `period` 是政权轴，song 与 liao-jin-yuan 全重叠 319 年，序上比会把遼行均《龍龕手鑑》
   （辽人之书而有宋刻本）误判为相斥。实测相斥由 20 降至 5。
2. **今人影印、整理、景印之丛编不为据**（`MODERN_REPRINT`）——《中華再造善本》
   《續修四庫全書》所收原本可以极古，其丛编之年不限原书。
3. **今人目录之卷次类目可为据，其书之成年不可为据。** 孫楷第《中國通俗小說書目》
   成于 1933（catalog_bound 得 modern 而无用），然其「宋元部」「明清講史部」自标所收之代，
   是为断代之判。「存疑目」「附錄」之属不入此列。
4. **`collection_bound` 取编者自定之收书下限，不取丛编影印之年**，二者与第 2 条不相妨：
   《續修四庫全書》1995 年影印而收书止于辛亥，故所收者无一晚于 qing。
   **世称之收书范围须实测复核**：《玉函山房輯佚書》世称「輯唐以前佚書」，
   实测所辑兼有宋人之书（《太平寰宇記佚文》《桂海虞衡志佚文》《後山談叢佚文》），
   「唐以前」不足为据，改据辑者之世（馬國翰 1794–1857）定 qing。
5. **歧义朝代名虽不能消歧，仍可得上限**（`AMBIGUOUS_LATEST`）——取诸解中最晚者：
   「宋」或刘宋（nanbeichao）或赵宋（song），无论何解皆 ≤ song。
   实测 600 条由此得上限，正是 catalog_bound 消歧无能为力之残余（见上文「899 条仅解 3 条」）。

#### 上限至轴首者即成定判

`pre-qin` 为轴之首，无更早之代可容——故上限得 `pre-qin` 者
径定 `period`，不止标 `upper`。实测 19 条（清华简 17、郭店 1、上博 1）由此定为 pre-qin。
出土之书多数前所未闻、从无记载可失，志书一路皆无，此源是其唯一可断之据。

#### 计上限时跳过错挂之著录

`indexed_by[]` 标了 `misattached` 的节（同题异书误并而挂上的著录）不计入上限（`scripts/period_bounds.py` 之 `tightest()`）——否则本书之判永远与非本书之著录相斥。实测标 222 节（涉 177 条 Work），`period` 与 `period_upper` 相斥者由 216 降至 38。`misattached` 的格式见 [common.md〈IndexEntry〉](common.md)。

来历：`period_upper` 2026-08-21 定；`misattached` 2026-08-21 设。

### 6.6 `authenticity`：判伪

**只有一个值 `forged`，且只在确定是伪书时才写。省略即无此疑义——这是绝大多数。**
不设 `genuine`：设了就得给七万条填，而其中六万九千条本无疑义；与 `loss_status` 之 `extant` 同理（全库只有 1 条，省略即今存）。**只标异常，不标正常。**

#### 「舊題某某撰」不是伪书，不要往这个栏里塞

这是两件事，混了就都表达不出来：

| | 说的是什么 | 怎么记 |
|---|---|---|
| **舊題撰人** | **撰人之题不确**。书本身不假 | `authors[].role = "舊題撰"`，舊題撰人与实际撰人并列 |
| **伪书** | **书是后人伪造而托之于古** | `authenticity: "forged"` |

「舊題〔朝代〕某某撰」是四库提要的常规措辞——《別本漢舊儀》「舊題漢議郎東海衛宏
敬仲撰」、《香譜》「舊本不著撰人名氏，左圭《百川學海》題為宋洪芻撰」——**这些都不是
伪书**。库中实测：舊題撰人 327 条，真伪书约 100 条。

舊題撰人之形态见《西京雜記》`1ev3bcikfdiww`：
`authors[0]` 劉歆·漢·**舊題撰**，`authors[1]` 葛洪·東晉·撰。二人并列，一层不丢。

#### 判伪三戒

判之所据须逐条读原文，**不可据关键词机械判**。实测中三种假阳性最多：

1. **说的是别的书**——《長安志》提要「慎喜偽託古書」说的是楊慎，不是本志；
   《廣博物志》「《三墳》為毛漸偽撰」说的是它所引之书。
2. **是否定句**——《章申公九事》「知非偽託」、《尉繚》「證其書先秦已成，非後人偽託」、
   《歲華紀麗》「不由震亨之依託」。
3. **是泛论**——《卜法詳考》「其為輾轉依託，可以概見」说的是历代卜书之通例。

又：**「缺 `period`」不是伪书的信号。** 实测全库 43.7% 无 `period`，
而有伪托之语者只有 22.9% 无 `period`——后者**反而比全库更常有**，
因为它们多半有四库提要。勿以此为据。

`authenticity_basis` 引提要或解题原文，逐条可验。

#### 与 `period` 的关系

**`period` 一律标成书时代**（实际撰人之时），不标舊題撰人之时。
`period_basis` 须写明「舊題某某（某代），實某代作，據某某」。
故《關尹子》：`period: song`、`authenticity: forged`、
`authors[0]` 尹喜·先秦·舊題撰——三层信息各得其所。

来历：2026-08-21 定。

### 6.7 `loss_status`：判存佚

一轴而已：**本书之文今日尚存几何**。字段不存在 = 今存或未考。各值界说见 [work.md](work.md)；判时要守的是：

**凡有文存世即 `partially_extant`，一字不存方为 `lost`。** 传本残卷、类书所引之佚文、后人之辑本，三者皆属 `partially_extant`——凡今日尚能读到本书几句者即是。泛言「殘缺」而不知所存何文者不足。`undetermined` 是考过而不能定，与「字段不存在」（未考）有别。`extant` 只在需要推翻既有推定时才明写。

**2026-08-21 订正：辑本改判 `partially_extant`。** 原判准作「原書無一存。類書所引之佚文、
後人之輯本，皆不改其為全佚」，与本栏所宣之轴（「本书之文今日尚存几何」）不自洽——
有佚文数条存世，「文尚存几何」之答即非零。原判准实际所用之轴是**传本是否断绝**
（传本尚在而缺卷者为残存，传本断绝而赖他书征引者为全佚），非「文存几何」。
二轴不同，混书于一栏则定义自相抵牾。今复归本栏所宣之轴。

「传本是否断绝」不因此丧失——它由辑佚档（`fragments`，今在 book-text）之有无导出：

| 现状 | loss_status | 辑佚档 |
|---|---|---|
| 全帙传世 | `extant` 或字段不存在 | 无 |
| 传本尚在而缺卷 | `partially_extant` | 无 |
| 传本断绝，赖类书征引／后人辑佚 | `partially_extant` | **有** |
| 一字不存，唯志书存其名 | `lost` | 无 |

**志书原文之「佚」字不即本栏之 `lost`。** 目录学传统之「佚」指传本失传，
与本栏之轴不同；志书所判记于 `indexed_by[].attested_status_raw`，本栏记本库之判，
二者本已分立。《經義考》逐书判其存佚（御製題：「次列題注曰存曰闕曰佚曰未見」），然**不得径改本记录之 `loss_status`**——四库御製題论此书自云「所注闕佚未見者，今四庫所録往往其書尚存」，即朱彝尊判为佚、为未见者，修四库时往往尚存；其判是十七世纪一人之见闻，非事实。`not_seen`（未见）尤不可转为 `lost`——那是「著者没见过此书」，与「此书已亡」不同轴。

**殘存不用 `fragmentary`。** 西方书目学之 fragmentary 专指「只靠他书征引之断片存世」，
而本栏之 `partially_extant` 兼含传本残卷与征引断片二者，范围广于彼，用之则以偏概全。

**不入本枚举的几件事：**

- **出土**不是存佚状态而是路径。原书久佚而赖简帛复见者，其状态即 `extant` 或
  `partially_extant`；出土之事由该 Work 的 Book（简帛实物）与「出土简帛」Collection 承载。
  又：出土之书多数（本库 257 部中 242 部）前所未闻，从无记载可失，本不需要此字段。
- **有辑本**不是存佚状态而是补救。由辑佚档之有无与 `collectors` 是否非空导出。
- **真伪**是另一轴。《古文尚書》今存而伪，《關尹子》今存而伪——并入本枚举即无从表达。
  真伪由 `authenticity` 承载，见〈6.6〉。

来历：`loss_status` 判准 2026-08-21 订正；`attested_status` 不得径改 `loss_status` 2026-08-06 定。

### 6.8 `dynasty`：怎么规范、怎么判

`dynasty` 是**直接显示给使用者**的朝代名。规范化之前库中有一百三十五种写法，含歧义（宋=劉宋/趙宋、
魏=曹魏/北魏…）、别名（後魏=北魏、姚秦=後秦）、误录（年号、帝王庙号误入朝代栏）、域外
（日本、朝鮮）等问题。**直接规范 `dynasty` 本身**，不另设 `dynasty_norm` 字段——使用者看到的
就应该是无歧义的学界通用名。

#### 规范化原则

1. **自明性优先**：规范名必须一眼能读出所属时段——三国系列必冠「三國」（三國魏、三國蜀、三國吳），南朝系列必冠「南朝」（南朝宋、南朝齊、南朝梁、南朝陳），宋分北宋／南宋。
2. **无歧义优先**：凡一字多朝者必加前缀（魏→三國魏／北魏、宋→南朝宋／北宋／南宋、蜀→三國蜀／前蜀／後蜀）。
3. **参照 CBDB**：规范名以 CBDB DYNASTIES 表为主要参照（冠词三國、南朝不影响对应）；2026-10-07 起只作人工校对参照，不存 `c_dy` 码（用户定，overview#464）。
4. **保留原文于 `indexed_by[].title_info`**：志书原文（如「毛詩義問十卷魏太子文學劉楨撰」）不受 `dynasty` 规范化影响。
5. **`period` 为派生字段**：`dynasty` 规范化后，`period` 可由 `dynasty` 自动归并导出（南朝宋→nanbeichao、三國魏→three-kingdoms）。
6. **判不出者留空并出清单**（`known-issues/dynasty未決.json`），**不猜**。

参考标准：

| 标准 | 性质 | 是否分北宋/南宋 | 是否覆盖十六国 | 是否覆盖辽金西夏 |
|---|---|---|---|---|
| CBDB DYNASTIES 表 | 学术界公认（哈佛/中研院/北大） | 否（在 reign 层分） | 是 | 是 |
| GB/T 47681.2—2026 | 国标（日历体系代码） | 否 | 否 | 否 |
| 文物藏品时代分类代码 | 行业标准 | **是** | 否 | 是 |
| 中研院史语所朝代代码表 | 机构标准 | 否 | **是** | 否 |

无单一标准完全满足文献分类需求，故**以 CBDB 为主体，参考文物标准补南北宋，参考中研院补十六国**。

#### 歧义朝代：逐条判定，不自动归并

| 原文 | 所含政权 | 判定方式 |
|---|---|---|
| 宋 | 南朝宋(nanbeichao) / 北宋(song) / 南宋(song) | entity 生卒年 + 著录志上限 + 作者已知朝代 |
| 魏 | 三國魏(three-kingdoms) / 北魏(nanbeichao) | period 三國志/魏書交叉验证 |
| 漢 | 西漢(qin-han) / 東漢(qin-han) | period 同属 qin-han（粗粒度自消歧），canonical 逐条判 |
| 周 | 先秦周(pre-qin) / 北周(nanbeichao) / 後周(five-dynasties) | 逐条判定 |
| 齊 | 南朝齊(nanbeichao) / 北齊(nanbeichao) | period 同属 nanbeichao，canonical 逐条判 |
| 梁 | 南朝梁(nanbeichao) / 後梁(five-dynasties) | 逐条判定 |
| 吳 | 春秋吳(pre-qin) / 三國吳(three-kingdoms) / 楊吳(five-dynasties) | 逐条判定 |
| 蜀 | 三國蜀(three-kingdoms) / 前蜀(five-dynasties) / 後蜀(five-dynasties) | 逐条判定 |
| 國朝 | 随编目之朝而异（本库多清、亦有明） | 按 source 判 |
| 當代 / 近代 / 現代 | 时段词，多指晚清至民国 | 逐条判 |

跨朝代值（秦漢、隋唐、齊梁、金元、遼金元、宋、齊）粗粒度可定 `period`，规范名仍逐条判；明末清初、宋末元初、元末明初连 `period` 也须逐条判。误入朝代栏的垃圾值（`@`、`不詳`、`明0`、年号、庙号、书院名、地域等）改为正确朝代或留空。各值对照表见 [common.md〈朝代与时代轴〉](common.md)。

另：歧义朝代名虽不能消歧，仍可得 `period_upper`（取诸解中最晚者，见〈6.5〉五事第 5 条）；而 catalog_bound 用于消歧几乎无用（899 条仅解 3 条，见〈6.5〉）。

#### `dynasty_basis`：各判法怎么用

判断依据逐条可验，写明用的是哪一种：

- `synonym`：同义归并（三國魏→曹魏、後魏→北魏）
- `entity_death_year` / `entity_birth_year`：作者 Entity 生卒年判定
- `catalog_bound`：著录志为时代上限
- `duandai`：断代志可径定
- `author_propagation`：同作者其他 Work 已判定值传播
- `manual`：人工复核

用 `author_propagation` 或以 Entity 之 `dynasty` 为据时，同守〈6.4〉：写明那个 `dynasty` 本身从哪里来，防闭环。

`dynasty` 规范化后同步更新 `index/works/*.json` 与 `index/entities/*.json` 中的 dynasty 字段（今由 build 重生 `index/`）。

来历：2026-08-08 定；参照 CBDB 而不存 `c_dy` 2026-10-07 用户定（overview#464）。
