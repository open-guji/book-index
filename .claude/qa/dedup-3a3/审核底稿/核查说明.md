# 3a-3 核查说明：异题名同书（一名／又名／原名／即）

你在核一批「两条 Work 可能是同一部书、只是题名不同」的候选对。每行 JSONL 是一对：
- `evidence`：触发候选的原文（`in_work` 是原文所在的 Work，`context` 是原文片段；`field=additional_titles` 表示仅凭该 Work 的「其他题名」字段，那是机器收集的，证据弱）。
- `A`、`B`：两条 Work 的摘要（题名、其他题名、作者、朝代、卷数、著录来源与原文摘要）。
- 需要更多信息时可读正式库文件（只读，切勿修改任何文件）：`/home/claude/book-index/Work/<id 倒数第三位>/<倒数第二位>/<末位>/<id>-*.json`，例：id `d59f8ii2o003` → `/home/claude/book-index/Work/0/0/3/d59f8ii2o003-法集錄.json`（用 `ls /home/claude/book-index/Work/0/0/3/d59f8ii2o003-*` 定位）。

## 判定（只认确定同一；错并难拆，漏并可等）
**同书**（全部满足）：
1. 原文确实在说「本书（in_work 那条）又名／原名／一名 X」或「X 即本书」，主语就是这部书，而不是书里的某一篇、书中提到的另一部书、某个人或年号；
2. 另一条 Work 确实就是那个 X：作者是同一人（或一方缺作者但无任何矛盾）、朝代相合、卷数相合或差异可由版本解释、著作领域一致；
3. 不是整体与部分（某书的一篇／一卷／一种）、不是原书与注本／疏／补／续编／节本／辑佚本／选本、不是丛书与其子目、不是同名异书。
同一部书的不同版本题名（坊刻题名、丛书本改题、如《逸雅》即《釋名》五雅本题名、《齊書》／《南齊書》）算同书。

**分立**：确定不是同一部书（部分对整体、注本对原书、续编、不同作者、别名其实指别的东西、泛称如「文集」「詩話」「年譜」等）。
**存疑**：可能是同一部，但证据不够（例如只有 additional_titles、一方无作者且题名常见、卷数差很大无法解释、原文说「疑即」「或即」且无旁证）。

证据只有 `additional_titles`、没有原文时：只有另一条 Work 的作者、卷数、内容描述都能对上才判同书，否则存疑或分立。原文用「疑即」「或即」「蓋即」时要有第二条证据（同作者＋同卷数等）才判同书。

## 输出
把结果写到指定的 TSV 文件（UTF-8，无表头，一行一对，制表符分隔，5 列）：
`A_id<TAB>B_id<TAB>判定(同书|分立|存疑)<TAB>保留建议(A|B|-)<TAB>理由`
- 顺序按输入；每对必须有一行，A_id/B_id 按 `pair` 字段原样（竖线左为 A，右为 B）。
- 保留建议：同书时选更通行、更完整的题名那条（通常著录多、版本多、是正题名的那条），其他判定写 `-`。
- 理由：一句中文，引用关键原文（如「提要：是書一名《竹香齋類書》，同為張墉撰」）。
最后在回复里只报三类各几对、以及你觉得最拿不准的 3 对。
