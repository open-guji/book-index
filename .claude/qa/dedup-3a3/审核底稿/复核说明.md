# 3a-3 复核说明（第二道独立复核）

每行 JSONL 是一个「簇」：members 里的 2～4 条 Work，有人认为是同一部书、只是题名不同；evidence 是触发候选的原文或「其他题名」。你是独立复核员，不知道前一位怎么判的，请自己判断。

判「同」必须全部满足：
1. 有据：原文明说某书又名／一名／原名／即另一书，或「其他题名」字段与另一条的题名、作者、卷数、内容都对得上；
2. 作者同一人（或一方缺作者但无矛盾）、朝代相合、卷数相合或差异能用版本解释；
3. 不是整体与部分、不是原书与注本／疏／评点本／删节本／增补本／续编／辑佚本、不是丛书与子目、不是同名异书；
4. 合并会把各条著录（indexed_by）并到一起：如果某条的著录里混了别的书（他人同名书、辑本、他书提要），判「存疑」。
同一部书的不同版本题名（坊刻题名、丛书本改题）算同。仅凭你自己的文献知识、库中没有任何对应依据的，判「存疑」。

可读正式库文件（只读，切勿修改任何文件，不做 git）：`/home/claude/book-index/Work/<id 倒数第三位>/<倒数第二位>/<末位>/<id>-*.json`，例：`d59f8ii2o003` → `/home/claude/book-index/Work/0/0/3/d59f8ii2o003-*.json`。辅助脚本请放在你自己的独立子目录里，别用公共文件名。

## 输出
TSV（UTF-8，无表头，一簇一行，3 列）：`cluster<TAB>判定(同|不同|存疑)<TAB>理由（一句中文，引关键依据；簇内只有部分成员同的，判存疑并写明哪几条同）`
回复里只报三类各几簇，以及最拿不准的 3 簇。
