# 3c：同題異作者中的責任者名誤字與佔位名（2026-10-25）

去重方案細拆單元 3c。基線 main `07fc66fc`，`scripts/dedup-census.py` 同題組裏「首位責任者不同」的兩類：異姓（非譜志）3,875 組、朝代不同 3,740 組。

## 做法

1. **差一字候選**（`cand_typo.py`）：組內兩條首位責任者名等長、只差一字，共 904 對。
2. **字形相似度**（`glyph.py`）：用文泉驛正黑渲染兩個異字，取整字與左右上下半字的 Dice 最大值，按形似度排序逐對判讀。
3. **逐對判讀**：判「誤字」「異體／避諱」「異人」「無把握」。只改有把握的；異人與無把握不改。
4. **獨立盲判**：把擬改的 168 項（打亂 A/B、不給答案）交兩個子代理各判一半。158 項一致；不一致或「不確定」的 7 項剔除不改（見候選表「存疑」）。
5. **佔位名**：在兩類組內篩帝號／年號寫法、朝代前綴粘連、時代泛稱、題名誤拆。朝代前綴另在全庫按嚴格條件（剩餘部分是已有人物主名且出現 ≥2 次、帶前綴的整名不是人物名、著錄原文含此寫法）篩出 22 處。
