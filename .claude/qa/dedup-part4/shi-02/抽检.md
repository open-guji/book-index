# 4a-α 史部 shi-02 抽检

独立子 agent 随机抽 48 组（10%，seed 27），只读 main 上的 Work／Book／叢書原文逐组判。

**结果：异质 0/48（异书 0，存疑 0）。**各组叢書首位撰者角色均为「撰」，无朝代矛盾。卷数除 2 组差 1（河汾淵源、雪堂校刊羣書敍錄，单行本唯一 Book 即同一叢書本）外全部一致。另有 3 组子目多出附刻一卷（讀史綱要、蘇臺麋鹿記、陝甘味經書院志），正文范围相同，判同书。19 组单行本已挂同一叢書的版本 Book。

若合并前 main 改到其中少数组，这些组会被剔出留待下批，其余在最新 main 上只重做应用与门禁（run_batch.sh REAPPLY=1），最终组数见 README。
