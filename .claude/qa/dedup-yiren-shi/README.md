## 做法与口径

1. `dossier.py` 出逐组材料；机器先分三类：两方首位都挂 Entity 且互不相同（899 组）、同科试卷（硃卷／墨卷／貢卷等）、其余逐组。
2. 逐组读＋全量「差一字／别名命中」扫描，先定 18 组并。
3. **独立抽检**（另一会话、盲判）：139 组里试卷类 0 错；其余**约一成被判成了分立，实为同书**，超过 3% 停批线。说明「两方挂不同人 → 直接判 C」这一口径在史部不成立：库里人物挂接常常就是错的（误字名、佔位名建了人物）。
4. 于是把非试卷类未抽的 738 组分 6 份全量独立复核，要求列出同书对并给把握（高／中）。原始结论 `复核结论.tsv`。
5. **高把握**（有书证或常识确定）连同自判共 132 组并；**中把握**（推断无直接书证、或卷数悬殊）不并，登 D（`复核存疑对.tsv`，理由照录）。复核员判「注本／评释本」的另立（史通评释降为 D）。
6. 试卷类：同科各考生之卷，差一字者亦为不同考生，全判 C。

被并的主要类型：误字（趙興時→趙與旹、葉東敬→葉秉敬、楊一清作「栂清一」「場清一」、楊廷和作「陽廷祁」）、异体（矦／侯、逈／迥）、字号谥号（薛文清＝薛瑄、椿園＝七十一）、佔位名（「晉世」「見道藏」「刻元」）、题名误切（「房唐才子傳」＝辛文房《唐才子傳》、「田茂園」＝康基田號茂園、「江少微」）、旧题与实撰（吳越備史 范坰／錢儼、地理指掌圖 蘇軾／稅安禮、籌海圖編 胡宗憲／鄭若曾）、序者刊者校者误题为撰者（北戶錄 陸希聲、革朝遺忠錄 杜思、顧氏詩史 顧正誼）、官修书不同总裁署名（实录、則例、續通典、大清律例）、无责任者条有总目原责任者或同版本互证。

keeper 取真撰者那条（误字一方作被并者）；字段冲突照 apply_batch 留在台账 `retained_alternatives`。
