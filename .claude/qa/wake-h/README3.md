# wake-h 第三輪：通名大 Work 的穷尽（主題組 H）＋中井竹山《逸史》立 Work

範圍：小學類書（說文、玉篇、廣韻、韻鏡、切韻指掌圖、古今韻會舉要小補、千字文、蒙求、三字經、百家姓）、類書（藝文類聚、初學記、太平御覽）、日本漢籍（日本書紀、和名類聚抄、懷風藻、日本後紀）與《逸史》。

方法：先於 origin/main 找出各書的 Work 與其下既有日本版 Book，再以 CiNii Books（count=200、year_to=1867／1911 逐頁）按題名及異體字（說→説、廣→広、經→経、鈔／抄等）檢索，過濾日本年號著錄，取 NCID 的 `.json`（出版者、刊記注記、所藏館）核版本；按（刊年、書肆、訓點者／校者）分版，同題同年不同書肆另立。NDL 僅作輔證（逸史九大、早稻田等）。脚本 build3.py＋items_*.py（`mk()` 自 NCID json 取館藏與出版者）。

結果：
- 新立 Work：逸史（中井積善，entity_id 沿用 hixhd2h9boo4）1；新建 Book 37（逸史 6、說文及五音韻譜 3、玉篇 6、廣韻／韻會小補／切韻指掌圖／韻鏡 6、蒙求 3、日本書紀／和名類聚抄／懷風藻／日本後紀 7、三字經 5、太平御覽 1 —— 見 ledger3.tsv）。
- 改掛：988g1xykgg（故宮藏明治九年大阪懷德堂刊《逸史》）由存疑目通俗小說 d59f2moz6nsx 改掛新 Work，revision 1.1.1，ai_note 說明。
- 未建及原因見 TODO3.tsv（出版者不明、書肆聯名難定、庫內無 Work、後印未定年等）。

口徑：弱證不建（年份僅目錄推定、出版者不明）；序跋年繫年者 certainty=inferred；edition 只寫頁面載明事實，刊寫形態著錄未明者不填 edition_type；同簇多 NCID 並條僅限出版者與刊年一致者，出版者不明的同題著錄一概不併、列入 TODO3。「昌平坂學問所」等出版者為 CiNii 編目者據題簽刊記所判，已於 ai_note 注明。

《逸史》要點：嘉永元年版刊記有「天保十三年官許上梓　嘉永紀元戊申鳩功」，故九大 NDL 著錄之「天保13年加賀屋善藏」本是否即嘉永元年版（以官許年著錄）未能定，依口徑另立互鏈。泉大津市立圖書館朴齋文庫「天保13年」為肉筆寫本，不建。
