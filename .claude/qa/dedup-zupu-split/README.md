# 拆开族谱多修聚合 Work（去重方案部分 6 附-族谱）

F 道把题名行、责任者行全同的多条上图记录并成一个 Work，族谱里常把同题的不同修次、不同支派（堂号不同）挂在一起。研-族谱口径（ai-team `研-族谱-族谱同题判定口径.md` 第六节，10-26 定甲）：各修各算一个 Work。清单来自 `.claude/qa/dedup-zupu/20261026/族谱-多修聚合Work.tsv`（262 个）。

## 规则
- 只拆题名是族谱的（含族譜／宗譜／家譜……且含氏、族、宗或世家）；清单里混入的谱录（說文諧聲譜、十友譜、詩譜、文譜）不动。
- Work 下的 Book 按「修」分组：组键＝Book 题名里的地望〔…〕＋卷数（title_info 去掉题名）＋刊年（publication_info.year 四位数；递修本的 year 是修年不是印年，不作键）＋堂号（edition 里「某某堂」，异体归一、去掉朝代与地名前缀）；年份、堂号都没有的以 edition 原文代。
- 键相同且有确切刊年的直接同组；其余每个 Book 自成一组，再按「同一修」合并，须同时满足：藏馆有交集；地望、堂号相容（同或一侧缺）；卷数相容（同或一侧为另一侧前段，「□卷／存卷N」与「不分卷」不相容）；至少一侧有确切刊年，且刊年相同、或两侧版本共有一个年号年（递修本）、或版本原文（异体归一后）全同。两侧都无确切刊年的不并（研-族谱口径判 D，宁分不混：不并的方向错了只是多一条 Work，以后可补并）。
- 人工例外（`MANUAL`）：孔子世家譜 d59fy68u06bk 的山東文獻集成本是民國二十六年鉛印本的影印本，同一修，不拆。
- Book 最多的一组留原 Work（并列取年份最早），其余每组新建一个 Work：抄题名、责任者等；不抄 indexed_by（总目一条记全部版本）、resources／resource_groups（影像带具体版本，分不清属哪一修，留原 Work）、merged_in、period／period_basis；分类照原 Work 所在节点补登。
- 改挂的 Book：work_id 指新 Work，revision 升 major，ai_note 记一行；原 Work revision 升 major，ai_note 记拆出的新 Work。

## 工具
`split_zupu.py --list <清单> --out <批目录> [--apply]`（cwd 正式库根）。台账 `splits.json`。

## 批次
- batch-01：242 个 Work 拆出 371 个新 Work、改挂 371 个 Book；13 个 Work 下只一修（或无 Book）不拆，6 个非族谱、1 个人工例外不动（台账 problems）。抽检三轮：首版 30 个判错 5（异体字、递修本、一侧缺堂号把同一修拆开；两修地望或卷数不同没拆；新 Work 抄了影像与并入历史）；二版重抽判错 2，另查出无年份组误并 7 个（「不分卷」对「存卷N」、无年份同堂号绕过藏馆条件），再改规则成本版。
