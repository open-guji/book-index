# 版刻语残片题名子目修正（2026-10-26）

叢書线（GUJI-526）拆《中國古籍總目》丛书子目时，有些子目题名里混进了版刻语，或整条就是一行版刻语（如「陽刻」「清同治九年刻」）。

## 已修（本 PR）
题名里带真书名的 4 条，去掉版刻语改题，所挂 Book 同改，版刻语移入 Book.edition：
- d59fy1cz0xz4「明萬曆間胡震亨沈士龍刻青烏先生葬經」→《青烏先生葬經》（津逮祕書）
- d59fysqu74zk「清乾隆元年鄂彌達刻春秋鈔」→《春秋鈔》（高安朱文端公藏書，朱軾）
- d59fywykh0jk「詩鈔清嘉慶三年刻」→《詩鈔》（五研齋全集，沈赤然）
- d59fxsffnq4h「詩集道光六年刻」→《詩集》（校禮堂全集，凌廷堪）

改题后与库中同题 Work（如朱軾《春秋鈔》d59f2mawki69、《青烏先生葬經》多条）是否同书，交查重普查按常规口径判。
