# wake-f（醫書組）第三輪：通名大 Work 窮盡
- 範圍：主題組 F（醫書：傷寒論、金匱要略、素問、靈樞、難經、本草、千金、外臺、脈經、各家方書）。先以 origin/main 全庫為準列出各書 Work 及既有 Book（git grep；bk.py／bt.py 為臨時工具，未入庫），再用 CiNii Books 題名檢索（count=200 逐頁，year_to=1911，日本年號過濾，wf3_cin.py）列出日本刊本，按（刊年、書肆、校點者）聚類，逐條核 NCID 頁的刊記／見返／藏版注記與所藏館（wf3_pn.py）。
- 產出：build3.py＋spec3.py 一次性生成 81 條新建 Book（涉 22 個 Work），所藏館錄自各 NCID 頁；ledger3.tsv 為台賬，TODO3.tsv 為未建原因（含建議補挂既有 Book 者）。
- 判準：刊記或書目著錄年份＋書肆＋校點者三者齊備才建；序跋年或叢書分冊推定年一律標 inferred；同年不同書肆或印次不明者不併入，互注於 ai_note。日本人撰注疏無 Work 者不硬掛。
- 自查：隨機抽 15 條對 NCID 頁回看（年份、書肆、所藏館），異質 0；全部 81 條年份與 NCID 著錄一致（程序比對），schema 檢查 ERROR 0。
- 經驗：CiNii 一個版本常被各館分別立成多個 NCID（書肆列序不同、見返／刊記著錄詳略不同），須依刊記及「藏版」注記聚類；叢書分冊（仲景全書）的出版事項取自他冊；年號與西曆不符者（元文6、天和4、天保12/1842）不建或注明。
