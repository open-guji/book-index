## 為何 scan D 只見一角

D 之所以報，全靠這批書**恰好另有** `period_upper=ming`（catalog_bound：焦竑一五九〇）。
沒設 upper 的同病之條，D 一條也不報。

實測：全庫繫《國史經籍志》之 work **16,046** 條，其 period 分佈為
`None 7807／song 1928／sui-tang 1811／ming 1441／nanbeichao 956／jin 740／qin-han 436／
liao-jin-yuan 403／three-kingdoms 236／five-dynasties 180／**qing 62**／pre-qin 44／modern 2`。
**qing 62 條佔 0.39%，是全表最刺目之異**；D 只報了其中 44。餘 18 條（山西通志、河南通志、
江西通志、雲南通志、浙江通志、廣西通志、欽定周易注疏、詞林典故、國子監書目、順天府志、
永平府志、江寧縣志、西陲要略、天文考異、孫子集注、論語說、毛詩譜、燕丹子、類纂、宋文選、
周易述說）本道續查——其中「欽定」「詞林典故」之屬多半不是斷代錯而是**磁鐵**
（清書誤掛明志之著錄項），性質不同。

## 建議之檢（掃法偽碼）

```
CAT_YEAR = {漢書藝文志:100, 隋書經籍志:656, 舊唐書經籍志:945, 新唐書藝文志:1060,
            宋史藝文志:1345, 國史經籍志:1590, 千頃堂書目:1670, 欽定四庫全書總目:1782,
            清史稿藝文志:1927, ...}          # 志之成書年，一次立表
for w in works:
    cats = {x.source for x in w.indexed_by} & CAT_YEAR
    if not cats: continue
    y = min(CAT_YEAR[c] for c in cats)        # 最早著錄之志 = 最緊之上界
    if PERIOD_START[w.period] > y:            # 該期之起年已晚於著錄之年
        報 (w.id, w.period, 該志, y)
```

此檢不倚賴 `period_upper` 之有無，可掃出全庫同型。
例 id：`d59f2mpu35kw`（唐宰相表）、`d59f2mpvncao`（中阿含經）、`d59f2md7ae4h`（朝鮮史略）。

## 併帶之一坑：〈清史稿行錯位〉在本庫有活標本

`d59f2md7ae4h`《朝鮮史略》。《清史稿藝文志》原文連寫二條：

> 朝鮮史略六卷。**不著撰人氏名**。朝鮮載記備編二卷，朝鮮史表一卷。**周家祿撰**。

切分時「周家祿」落到了錯行，《朝鮮史略》遂憑空得一清末撰人，period 隨之為 qing。
同條所繫《欽定四庫全書總目》獨立證其誤：「一名《東國史略》，**不著撰人名氏，乃明時朝鮮人所紀**」。
已刪誤落之撰人、改 period=ming。
**判準**：凡撰人出自《清史稿藝文志》而該志原文中該撰人之前尚有第二個「N卷。」者，一律棄權覆核。

## 又一坑：以 period 倒推撰人，再以撰人立 period

`d59f2mpvncao`《中阿含經》之 `authors[0].name_basis` 自書：
「著錄作「高宗」，非姓名而是廟號……**本書之撰人朝代作「清」**，清之高宗即乾隆帝弘曆」——
而該條之 `period_basis` 正作「據 authors[0].dynasty「清」」。**兩欄互為據，環而無所出**。
判準：`name_basis` 引 period／dynasty 為據、而 `period_basis` 又引該 author 者，即是此環，須外證斷之。
