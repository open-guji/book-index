# 別道之單向邊二條（人指書而書不指人），擋 `verify.py --strict`；皆「姓名黏連」拆分之遺

[qing]

合流 origin/main（新增之「單向邊」檢）後，本道把自己的 14 條清乾淨，餘二條非本道所有：

```
單向 ('hixhd2h9bj8w', 'd59f2evwx7nn')   徐子(戰國/pre-qin) -> 平徐氏珞琭子賦注 period=song
單向 ('hixhd2h9bmw8', 'd59f2evpqr5t')   周生(先秦/pre-qin) -> 烈要論        period=three-kingdoms
```

二者同型，皆 skill〈姓名的四種黏連〉之誤拆，且**work 側已由某道改正而 entity 側未隨**：

- `d59f2evwx7nn`《平徐氏珞琭子賦注》撰人今作「**徐子平**」（宋，星命家），無 entity_id。
  而 entity `hixhd2h9bj8w` 之 primary_name 是「**徐子**」（戰國）——舊拆作「徐子」＋「平」，
  「平」被當成題名之首字（今題名猶作「**平**徐氏珞琭子賦注」，疑亦是此拆之遺，當作
  《徐氏珞琭子賦注》，請該道覆核）。
- `d59f2evpqr5t`《烈要論》撰人今作「**周生烈**」（魏，見《三國志·王肅傳》注），無 entity_id。
  entity `hixhd2h9bmw8` 是「**周生**」（先秦）——舊拆作「周生」＋「烈」，
  「烈」被當成題名之首字（今題名猶作「**烈**要論」，實當是《要論》，周生烈撰）。

處置（該二道或協調者）：自 `hixhd2h9bj8w.works`／`hixhd2h9bmw8.works` 移出該 work_id 即可解單向邊；
題名之首字是否亦為誤拆，請一併覆核（撞庫後再改題）。
`hixhd2h9bj8w` 名下尚有 `d59f2evs8ni9`，未查，一併請覈。

本道之 `verify.py --strict` 以此二條為餘數，非本道所增；非 strict 之 verify 全綠。
