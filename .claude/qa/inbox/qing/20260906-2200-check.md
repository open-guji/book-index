# 坑：2026-08-24「補繫entity：……庫中以此為別名（alt_names）者唯一」套語族——「唯一」只是彼時之唯一，非今之唯一，且完全不覆核代／生卒

[qing]

## 現象

`grep -rl '庫中以此為別名（alt_names）者唯一' Work/` 命中 **139 條**（全庫）。
此語出自 2026-08-24 前後一批自動化「補繫 entity」流程：撰人名若無 entity_id，
且該名以 alt_names／別名／代相鄰等條件比對後**只得一個候選**，即逕繫之——
**不覆核著錄原文、不覆核候選之生卒是否與本書可能之成書年相容**。

## 本道核出之三型錯誤

### 一、廟號跨朝碰撞（因「彼時之唯一」非「今之唯一」）

「宣宗」六書（見批20 commit）——2026-08-24 時庫中**尚無獨立之「清宣宗」entity**，
故「宣宗」比對 alt_names 只得「明宣宗朱瞻基」一個候選，逕繫之。**其時之「唯一」
只是彼時庫之建置未全，非真唯一**——今庫中早已補上「清宣宗」，此語遂成過時之偽證。
**判準**：凡此套語所繫之 entity 若不含所屬 work 之期（如本條 period=qing 而繫代明之
entity），先查是否已有更貼期之「清X」／「該代X」entity 存在，存在則逕改。

### 二、同名而代不合，未覈生卒／版本紀年即繫（5 例，本道已解）

文秉→孫錝（明1538生，實文秉1609–1669）、德俊→徐即登（明1544–1626，實著錄道光
廿六年抄本）、長善→徐乾貞（卒1668，實著錄光緒五年刻）、超凡→胡尚英（明）、
有常→王全綱（1853生，實著錄《國史經籍志》1590年輯，早於候選出生二百六十年）——
**皆「別名唯一」即繫而未覈生卒與版本／著錄紀年之明顯不容**。

### 三（對照組）：確有其據者不誤

陸龍其→陸隴其（entity alt_names 明載「陸龍其」）、武靖→黃翼升（entity alt_names
明載「武靖」為諡號）、項廷紀→項鴻祚（著錄逕稱「(清)項廷紀撰」，本名改字之實）、
潘咸→潘鹹（著錄「清潘咸撰」，異體字）——此類「唯一」有著錄或 alt_names 雙重印證，
非誤。**故此套語族不可一概而論，須逐條覈著錄／生卒，唯覈後方能斷其正誤。**

## 建議之檢（掃法偽碼）

```
for w in works_with_this_basis_pattern:
    a = w.authors[matched]
    e = entity(a.entity_id)
    if e.birth_year and 本書可能之最早成書年 (取 indexed_by 之刻本紀年／period 下限)
       and e.birth_year > 本書可能最早成書年:
        report(w, e, '候選生年晚於本書可能成書年——矛盾')
    if e.period and w.period and 兩者相距逾一世代 (60年) 且無首尾相接之理由:
        report(w, e, '代之差過巨，逕繫可疑')
```
