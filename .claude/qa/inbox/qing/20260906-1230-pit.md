# 坑：`collection_bound：《續修四庫全書》收錄止於辛亥以前` 是叢書之凡例，不是單書之證——其自身著錄之版本已否之 63 次

[qing]

## 徵候

`period_upper_basis` 作：

```
collection_bound：本書收入《續修四庫全書》——其書收錄止於辛亥（1911）以前之著作，故不晚於 qing
```

全庫用此句者 **312 條**（`grep -rl 'collection_bound：本書收入《續修四庫全書》' Work/`）。

## 為何是坑

《續修四庫全書》之凡例確稱收「乾隆以後至民國元年前各類代表性著作」
（https://zh.wikipedia.org/wiki/續修四庫全書 ）。然此是**取材之準**，非其實收之界。
在這 312 條裡，**63 條**之 `indexed_by[].edition`（即《續修四庫全書》自著之版本）
明題民國以後之印本，自證其例有出入：

| id | 題名 | period | 著錄之版本 |
|---|---|---|---|
| d59f2ofm5c01 | 法言義疏 | modern | 影印浙江省圖書館藏**民國二十二年**鉛印本 |
| d59f2ofukqgw | 清史紀事本末 | modern | 影印**民國三年**石印本 |
| d59f2q8hy70i | 春秋復始 | modern | 影印**民國七年**北京大學鉛印本 |
| d59f2ms1oo3k | 太平天日 | qing | 影印**民國三十七年**商務印書館影印本 |
| d59f2msijhfk | 水經注疏 | qing | 影印**一九五七年**科學出版社影印抄本 |
| d59f2ms1zwn4 | 李秀成自述原稿 | qing | 影印**一九六二年**臺灣世界書局影印本 |

以叢書之凡例反推單書之成書年代，正是 skill〈繫連寧缺毋濫〉所戒之孤證；
何況此凡例連叢書自己都未嚴守。

## 判準

**`collection_bound` 一族之 basis 不足以立 `period_upper`**，凡遇之：
先看本條 `indexed_by[].edition` 有無紀年——**版本之年才是硬據**（版本不早於成書）。
著錄自題民國以後之印本者，該 upper 逕刪。

## 本道已做者

D 類（period_upper 早於 period）qing+modern 50 條中，此型 5 條，五條之著錄皆自題民國印本
（法言義疏、顏氏家訓補校注附錄、清史紀事本末、胡刻通鑑正文校宋記附錄、春秋復始），
已刪其 period_upper 與 basis，原值錄於各條 ai_note，可逆。**period 一條未動**。

## 待協調者裁者（非本道所能及）

餘 307 條之 `period_upper` 多與 period 同值（故 scan D 不報），無邏輯之牴，
但其「據」仍是這句不足信之話。是否全庫改寫其 basis、或逕刪之，請協調者定。
另請留意：此 63 條中 `period=qing` 者 **176 條**裡，頗有實成於民國之書
（如 `d59f2mvrlh4x` 太炎文錄、`d59f2msijhfk` 水經注疏、`d59f2mrwdmv4` 晉書斠注民國十七年、
`d59f2mvp3ksg` 愚齋存稾民國二十八年），乃 qing／modern 之界，本道另批處置。
