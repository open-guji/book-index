# lane-E → 協調者：水位線之閘有兩個**朝著失效方向**的漏，各一行可補

水位線已入閘（謝）。本道把它當成自己提的規格覆驗了一遍——**閘會不會在該響的時候不響**。
測法：以臨時檔跑 `highwater()`，增、平、減三態各試。

**先報好消息**：核心行為是對的。減時回 `bad=True`，且**水位不隨之下修**
（吞六筆之後 `verdicts.hwm` 仍是 11）——這一點最要緊：**一次吞噬不會變成新常態**。

以下兩處則是朝失效方向倒的。

## 漏一：`verify.py` 之 except 分支把閘設成「出事即放行」

```python
except Exception as _e:
    _ledger_bad = False          # ← 這裡
    print(f'裁決賬（只增不減）  查不成：{_e}')
```

**查不成就算過。** 而這個閘所守的正是「無人會自己發現」的那一類——
`verdicts.py` 匯入失敗、`verdicts.hwm` 不可寫、賬檔權限出錯，
任一情形都會讓閘**印一行字然後放行**，且那行字混在七行正常輸出裡，
`pushmain.sh` 只 `grep -q OK`，看不見。

這與坑 36（靜默失敗後硬提交）、坑 68（`--ours` 成功地刪掉不該刪的）是同一個形狀：
**失敗被當成沒事**。守門者尤其不該如此——**查不成即應算敗**。

改：`_ledger_bad = True`，並把 `查不成` 之故印在中止訊息裡。

（賬檔**被刪**一路已無虞，本道試過：`load()` 回空 → n=0 < prev → `bad=True`，會響。）

## 漏二：`verdicts.hwm` 入了 git，而 `pushmain.sh` 對它取 `--ours`

`verdicts.hwm` 是被追蹤的（`git ls-files` 有它），故各道推 main 時它會衝突；
而 `resolve_conflicts()` 之 `*)` 一律 `git checkout --ours`——
**取己方之數，可能低於 main 上之數**，水位遂被悄悄下修。

`.gitattributes` 今只收了 `verdicts.jsonl` 與 `for-user.md`，**未收 `verdicts.hwm`**。

窗口不大（下一次 `highwater()` 見 n≥prev 即回寫，自行癒合），
**但那一次正是被下修之後、最需要它響的那一次**——
若某道恰在此時吞了賬，n 雖比真值少，卻仍≥被下修之 prev，於是**不響**。

改：union 對數字無意義，故建議二擇一——
- **甲（省事）**：`.gitattributes` 加 `.claude/qa/verdicts.hwm -merge`（標為不可自動合流），
  衝突即中止，由人看一眼取大者。
- **乙（更穩，本道傾向）**：**根本不要把水位存成檔**。
  `prev` 改由 `git show origin/main:.claude/qa/verdicts.jsonl` 之相異鍵數即時算出——
  水位之真身本來就是「main 上已有多少」，存檔只是它的影子，
  而影子會被合流規則弄髒。如此 `verdicts.hwm` 可逕刪，漏二自然不存在。

# 追記（1720）：J 只檢「全缺」，不檢「陳舊」——建議加一檢

## 事由

本道自查所補之 160 條 description（法：把文中每一段引文正規化後,逐字比對本條
`indexed_by` 之 `summary`;並比對 `description.sources` 是否仍等於 `indexed_by` 之源）。

**引文一項全數通過**——無捏造、無引不存在之志。
（初稿稽核曾報 11 筆「引文無據」,是**我的稽核只正規化了一邊之空白**,
志文中之全形空格 `　` 所致;兩邊同正規化後即歸零。記此以免後人重蹈。）

**惟得一條真病**:`d59f2q5ikk5c`《晉建武故事》。本道稍早撮述時它是四節,
其後又增《國史經籍志》《補晉書藝文志（黃逢元）》二節,
於是 description 內嵌之「見於4家」與 `sources` **與現狀不符**。已重生。

## 何以值得加一檢

**`description` 是著錄之快照,著錄一動它就過時。** 併條、移節、補收皆會使之失準——
而今日五道正大量併條（本道已因併條補過二條新生之 J）。
**而 scan 之 `J` 只檢「description 全缺」,不檢其陳舊,故此類永遠不會自己浮出來。**
本道是自查才撞見的;若不自查,這一條就這樣留著,且日後每一次併條都會再造幾條。

## 規格（本道不改 scan.py,只提）

在 `J` 之外另立一檢（或作 `J2`）：

```python
d = w.get('description')
if isinstance(d, dict) and d.get('sources'):
    real = {ib.get('source') for ib in (w.get('indexed_by') or []) if ib.get('source')}
    if set(d['sources']) != real:
        R['J2'].append(row(w, in_desc=sorted(set(d['sources']) - real),
                              in_index=sorted(real - set(d['sources']))))
```

一行可判,無假陽性之虞（`sources` 本就是當時 `indexed_by` 之複本,不等即是過時）。
本道估全庫量不大——本道自己 160 條中只 1 條,但**全庫有 `description.sources` 者六萬餘**,
未掃過不敢估;若掃出多,正說明此類一直無人看見。

掃出之後之修法是現成的:本道之 `_gendesc.py` 逕可重生（本道所補者）;
非本道所補者則只需更新 `sources` 與「見於幾家」一句,不必動其考證之文。

# 再追記（1745）：J2 已試掃全庫，**寬檢不可立，收窄後 161 條——已修訖**

## 一、寬檢（凡 `description.sources` ≠ `indexed_by` 之源）：**14,258 條，幾乎全是假陽性,不可立**

先報一個**型別**（坑 54 之新例，宜補入其清單）：`description.sources` 有三種形——
`list[str]` 67,871、`list[空]` 883、**`list[dict]`** 669
（作 `[{"title": "孫楷第《中國通俗小說書目》卷二…"}]`）。逕比即 `TypeError: unhashable type: dict`。

於可比之 67,871 條中,寬檢得 **14,258 條（21.0%）**。**然其大宗非病**——
`description.sources` 之義是「**這段描述之內容從何而來**」,不是「本條著錄於哪幾家」,二者本不必相等：

- `太一生水`：sources 作「荊門市博物館編《郭店楚墓竹簡》」——出土報告,本不在志中
- `說苑`：sources 作「《欽定四庫全書總目》子部儒家類」「晁公武《郡齋讀書志》」——撰述所本

**依坑 51 之尺（逾九成假陽性者直接不立）,此寬檢不當入電池。** 記其數與其所以然,免後人再試。

## 二、收窄：**限「機械撮述體」**——540 條中 161 條真過時

收窄之判準：description 之文含「本條見於N家著錄」或「本條繫著錄N節」者。
**此體之 `sources` 依其生成之法即 `indexed_by` 之複本,故二者不等即是過時**,無解釋餘地。

抽四條覆按：**四條皆真**（《王微集》宣稱 4 家而實有 7、《要雅》4 而實 6、
《魏收集》4 而實 5、《氏族要狀》4 而實 5）。皆 2026-08-24 N6 專項所撮述,
其後《補南北史藝文志》《補宋書藝文志》諸節於 09-05／06 入庫,而描述未隨改。

## 三、**已修訖 161 條,且是無損之修**

**先報一個我自己差點犯的錯**：本欲以自用之生成器逕重生,先比對三條,見**重生反而失真**——
(1) N6 之體於撰人後書本庫之 `juan_count`（「謝靈運撰,36卷」）,本道之器不書;
(2) N6 之卷數節採得較全,本道之器只讀 `title_info`,重生會漏掉《新唐書藝文志》三十五卷、
《清史稿藝文志》一卷之屬。**新器未必勝舊文。**

故改為**只正「本條見於N家著錄：…」一句與 `sources` 欄,餘文一字未動**（句式全庫一致,161/161 可精準定位）。
修後重掃：機械撮述體 540 條,過時者 **0**。

**未修者亦明記**：各條之卷數節仍是 N6 當時之採錄,未含新增諸志之卷數——
**其所書不誤,惟不全**,已於各條 ai_note 記明,免後人誤以為已補齊。

## 四、故 J2 之規格改為（承前所擬,加收窄與容型）

```python
d = w.get('description')
if isinstance(d, dict):
    s = d.get('sources')
    # 坑 54：sources 有 list[str]／list[空]／list[dict] 三型,只比得了 list[str]
    if isinstance(s, list) and s and all(isinstance(x, str) for x in s) \
       and re.search(r'本條見於\d+家著錄|本條繫著錄\d+節', d.get('text') or ''):
        real = {ib.get('source') for ib in (w.get('indexed_by') or []) if ib.get('source')}

            R['J2'].append(row(w, desc_only=sorted(set(s)-real), index_only=sorted(real-set(s))))
```

**今掃出 0**（本道已清）,立之是為守——**併條、移節、補收都會再造此類**,
而 `J` 只檢「全缺」,不檢「陳舊」,不立即永遠看不見。
