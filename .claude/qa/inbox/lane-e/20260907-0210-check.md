## 二、**「著錄 ≥4 源」在這一批裡不等於「四家獨立的見證」**

158 條之著錄源分佈：

| 源 | 條數 |
|---|---:|
| 補晉書藝文志（秦榮光） | 155 |
| 補晉書藝文志（文廷式） | 127 |
| 補晉書經籍志（吳士鑑） | 115 |
| 補晉書藝文志（黃逢元） | 91 |
| 補晉書藝文志（丁國鈞） | 46 |
| 隋書經籍志／新舊唐志／國史經籍志等 | 各 ≤23 |

**晉世本無藝文志**——這五家都是清人各自回溯補撰，且彼此相沿（黃逢元、吳士鑑、秦榮光之案語屢書
「見《隋志》」「据《舊唐志》」，所據其實是同一批唐前舊目）。**155 條之「4 源」中有 2–4 源是這五家。**

故本批之描述於卷數、著錄兩節之後，加一句明著其數與其性質，
使後人不致以「見於四家」為四證。**這一句是本批唯一逾出「照錄著錄」之處，
而它所陳者仍是本條 `indexed_by` 之事實（哪幾家、幾家），非本道之考證。**

## 三、生成之法（依 v1 N6／J11 之例，`_gendesc.py`）

五節，**每節皆據本條 `indexed_by`，不出其外；凡著錄所無者一字不書**，無據之節整節略去
（不以「不詳」「未詳」充數）：

1. **撰人**：取 `authors[]`（名＋代＋役）。空則書「諸志之著錄不著撰人」——
   此是**著錄不著**，非**其書無撰人**（庫例見 SCHEMA〈無撰人 Work 非缺陷〉）。
2. **卷數**：自各節 `title_info` 抽之（附録之「録一卷」不計入正卷）。一致則「諸志皆作X卷」，
   不一則逐家列之。**異體之數歸一**（隋志「一十卷」與國史志「十卷」同是十，不作異文報）。
3. **著錄諸志及其部類**：部類取 `author_info`／`section`。
4. **諸志之著錄語**：逐字引之，**不代為判斷**。佚文出處與輯家皆在其中
   （「《世說·方正門》注」「《御覽》五百一十一」「今存嚴輯本」）。逾 200 字者節錄，全文仍在 `indexed_by`。
5. **存佚**：有 `loss_status` 則書之；否則取諸志之 `attested_status` 並**明言那是志家之判非本庫之判**。

末綴「未覆核原書」——依派工單所囑，亦是 v1 之例。

### 生成器上踩到的三個坑，記之

- **`author_info` 這一欄名為「撰人」而所載者不一**：多數是部類（「見史部·別傳類」），
  亦有逕書「不著撰人名氏」者。初稿照收，遂生出「《欽定四庫全書總目》**列於不著撰人名氏**」這種話。
  今只認確是部類者。**坑 54 之通則（讀任何欄先問有幾種型）不只適用於掃描器，也適用於寫入器。**
- **引文入「」須先把內層「」降為『』**，否則《吳士鑑》「《隋志》云：『梁有，亡。』」一節會生出
  `「…「梁有，亡。」。」` 之壞括號。
- **《四庫總目》之提要動輒數百字**，全錄則描述失其為描述。故設 200 字之節錄並明言其截。

## 四、**兩條不作一書之描述**——坑 51 之已知「一 Work 誤植兩書」

`known-issues/undated-20260906-一Work誤植兩書三例.json` 所記三例，**其二在本批之內**
（`d59f2psgsem9`《千金方》、`d59f2pwuqha9`《名山記》；第三例《外國傳》不在 J）。
此類條若逕作一書之描述，**就是替一個已在案的錯誤背書**——描述會把范世英三卷本與孫思邈三十卷本
寫成同一部書之異文。故此二條之描述**開宗明義先書其兼兩書**，再照錄諸節，
並明言「不代為合一之判」。拆條須先撞庫（孫思邈《千金方》、王嘉《拾遺記》庫中多半另有專條），
該案原議即取「乙：先記案不拆」，非本道所辦。
