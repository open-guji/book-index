`d59f2q8wb474`（故宮巴利函題，題斷在「法言莊嚴．**第**」）

```
波羅提木叉，攝阿毗達磨義論，業處，訓世，字意分別想，名詞筆記，法言莊嚴．第九冊
```

**Work 側之題被截而 Book 側完整**（二者同出一次匯入）。以 Book 之題補之，是從原文，非臆補。

**批一之失不在判斷，在搜索範圍**：我判「取不到」時只往庫外想，沒往同一實物的另一側看。
同族另二條（`d59f2pzq21hd`、`d59f2pvgsidc`）之 Book 題與 Work 題**逐字相同**——

## 三、清史稿「又續補」：覆得原文，且庫中有先例，然仍不改

`d59f2naafz0g`——批四判「未檢得其行」。本批取《清史稿》卷一四五（四書類）得：

```
四書釋地補》一卷，續補》一卷，又續補》一卷，《三續補》一卷。樊廷枚撰。
```

即「又續補」是**序次之名**，非承前之辭。而**庫中有直接先例**：
`d59f2nv5s6io`《四書釋地又續》閻若璩撰，其 `title_info` 僅作「又續」（同一 `source_bid`），
本庫題之為「四書釋地又續」——**本庫於序次之名採「母題＋序次」，不留孤名**；
該條 ai_note（2026-08-24）並考定四庫提要之版本來源，判其「各自行世之書，非隨本之部」而不併。

**依此先例本條當補母題。仍不改，兩個理由：**
1. **母題之形二說，原文不足以決**：(甲)《四書釋地又續補》——與閻書《釋地》《續》《又續》《三續》
   逐一相對，樊書補其四種；(乙)《四書釋地補又續補》——以樊書《四書釋地補》為母題。
   庫中 `d59f2mrfu22o`《四書釋地補續補又續補三續補》（續修四庫，四名連書）兩說皆可讀。
2. **此事牽連三條而本檢只報其一**：同族之 `d59f2naafz0h`《三續補》同病，
   而其題不以「又」起首，**G2 掃不到**；志中之「續補」一種庫中未見。
   只改本條會把四個一體的名弄成三種寫法。**宜四條同時定。**

## 四、一件該報而未修的：Book 側之題未隨 Work 同步

本道批一改了八條「 題」殘（《中華再造善本》著錄行之截斷），
但**其 Book 側之 title 仍作舊形**（「孔叢子七卷釋文一卷 題」「尙書十三卷 題」「新雕洞靈眞經五卷 題」）。

本道未動 Book——**Book 之 title 是那件實物之著錄行，未必該與 Work 之正題一致**
（如「押韻釋疑」↔「押韻釋疑五卷拾遺」正是常態）。
但「 題」那個殘字是兩側都有的**同一個錄入殘餘**，與卷數之附載不同性質。
**改不改 Book，本道不敢定**（Book 屬何道未見明文），列此請協調者裁。
