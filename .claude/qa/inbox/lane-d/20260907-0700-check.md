## 四、已解之二條，靠的是庫中同段之先例

- `d59f2ptei136`「又十卷孔安國傳，范寧注。」→《古文尚書》。
  舊唐志卷四六書類：「《古文尚書》十三卷孔安國傳。／又十卷孔安國傳，范寧注。／又十卷李顒集注。……」

  （馬融、鄭玄、李顒、姜道盛、王肅、謝沈）——**八條之中獨本條未解**，
  蓋其文有二注家而中夾一逗，解析者於此失手。
  今依同段諸條之例正題、析出撰人、補 entity 反邊，連 `note` 之措辭都用與諸條相同者，
  **卷數亦同諸條留 null**（免與彼異）。
- `d59f2q0ubnk0`「又一卷釋道騫撰。</poem>」→《楚詞音》。
  舊唐志卷四七楚詞類：「《楚詞音》一卷孟奧撰。／又一卷徐邈撰。／又一卷釋道騫撰。」
  庫中主條（孟奧）與同型已解之徐邈條俱在，徐邈條之 `title_info` 正作「又一卷徐邈撰。」。
  **末綴之 `</poem>` 於此亦得解**：該段在原文中以 `<poem>…</poem>` 包裹，
  本條是段中最末一行，抓取時把閉合標記一併帶入——**故那不是題之一部，是抓取之殘**。

## 五、「又」不一定是承前——標點可別，但只在某些志可用

《宋史》卷二〇九總集類同一頁上有一組**最小對照**：

```
丁逢《郴江前集》十卷又《後集》五卷      ← 承前之「又」，在《》之外
黃學行《又乙集》一卷                  ← 題中之「又」，在《》之內
徐大觀《又續集》四卷                  ← 同上
```

且該類本有《乙集》《續乙集》《續集》相次成列（黃岦《續乙集》八卷、劉褒《續集》十二卷），
「又乙集」「又續集」正是此系列之名。故二條判 `normal`。

**惟此法不可通用。** 本道查各志 `title_info` 帶《》之比率：

| 志 | 節數 | 帶《》 |
|---|---:|---:|
| 宋史藝文志 | 9,174 | 100% |
| 國史經籍志 | 16,110 | 100% |
| 舊唐書經籍志 | 2,980 | 93% |
| **新唐書藝文志** | 5,215 | **0%** |
| **清史稿藝文志** | 8,822 | **0%** |
| **崇文總目** | 3,410 | **0%** |
| **千頃堂書目** | 12,600 | **0%** |

於後四志此法全然無效；而於國史經籍志，100% 帶《》反而意味**括號可能是錄入所加**，
未必是原書所有——所以那三條仍不敢據《》斷之。
（本道前一批之 ask 曾擬此法，今補其適用之界。）
