## 一、最要緊的一件：推 main 被拒之真因，不是 classifier

本道開工時 `git push` 即被拒，錯誤全文：

```
remote: access denied by the git proxy: open-guji/book-index is not in this
session's authorized repository set, so the proxy will not inject a credential
for it. To fix, add the repository to the session's sources.
```

**倉不在本 session 之 sources 裡**。本道之容器開工時 `/home/user/book-index` 根本不存在
（交底說「已 clone」，實則沒有），是自行 `git clone` 的——而自行 clone 者，proxy 不予注入憑證，
**fetch／merge 走公開讀取可行，單擋 push**，症狀與 lane-A 自陳者一字不差。

以 `add_repo(owner=open-guji, repo=book-index, access=push)` 掛上之後，一次即推成。

協調者 02:05 之記把 lane-A 此案結為「虛驚」，據的是「賬中有它 308 筆」——
**那隻證明它前幾批推成了，不證明它後來沒被擋**。二事可以並存。
**建議：新開之道第一件事就是驗這一步**（`git push --dry-run` 或逕看 sources），
不要等攢了三批工才發現。

## 二、判準之立法，兩條可覆用之通例

### （一）病在 entity 側，不在 work 側——F 之最大一類

F 之報常被讀成「work 之撰人名錯了」，實則本道所辦 F 中 **12 條之病在 entity**：
work 側早經 2026-08-24 N4／N6 壞名正名、J3(2) 正名或 2026-09-06 qa-sweep 剝殘語訂正，
而 entity 之 `primary_name` 仍是壞形，於是二者不合。

夫裴松之／粱祖𣈶之／乾隆三十二年傅恆／南唐何晦／貝勒奕繪側室顧太清／碌鸞／董助／
徐瑜宜／釋惠皎／希聲／殷闡——一望可知皆是黏連或殘形。

**判法：看 `authors[].name_basis`。** 有 2026-08-24 之後的正名記錄者，即是 entity 滯後；
舊形一律降入 `alt_names`（type=舊著錄形），不刪一字。

### （二）「一字之差」該存原形抑或該改——以「所差者在名之內抑或名之外」為斷

lane-A 已誡「一字之差不是判準，逐對裁定的字表才是」。本道再進一步，立一條可操作之界：

- **所差者在名之外**（官職、地望、國別、朝代、役字、「等」、年號、位號、括注校語）
  → **剝**，依坑 20 與 lane-A 之 H-官職黏名同法：`name` 只存姓名，著錄原形入 `name_basis`，
  身分官職入 `title_or_office`。本道剝 23 處。
- **所差者在名之內**（異體、形訛、衍字、闕字）
  → **存**，判 `normal`：`authors[].name` 存著錄原形，entity 存歸一之名，二者相異本是庫例。
  本道存 35 處（曹學牷／俞琬／朱謀韋／盧綝／皇甫議／賣充／荀煇／管格／陳長壽／張輯／何質真）。

**此界所以要緊，見下節。**
