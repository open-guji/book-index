# 坑：「L5 斷代歸一」之「確證」句是循環的，56 個 entity 中 28 個所據不成立

2026-08-25「L5 斷代歸一（遼金元輪）」把一批 entity 之 dynasty 由單代（元／金）改為
「宋末元初」「元末明初」，其 `dynasty_basis` 皆是同一句式：

> L5 斷代歸一（2026-08-25 遼金元輪）：本欄舊作「元」，而其書之著錄源《欽定四庫全書總目》
> 作「宋某某」。二說皆非全誤——其人是**過渡期人物**，生於前朝而書成於後朝（或反之）。
> 庫中本有「宋末元初」一值正為此設，今歸之。**確證：其人名下之 work 同時分居
> liao-jin-yuan×N 諸桶。**

末句是全句唯一的獨立佐證，而它把**一桶之內的 work 條數**寫成了**分居諸桶**。
`liao-jin-yuan×3` 讀作「三書同在 liao-jin-yuan 一桶」才是實情，並非跨桶。

實測（全庫掃 `dynasty_basis` 以「L5 斷代歸一」起首者）：

```
L5 斷代歸一 之 entity 共 56
  名下有期之 work 只落一桶（「確證」不成立）：28
  真跨二桶以上：                              28
```

那 28 個之「過渡期人物」判斷等於只剩「舊值作元、四庫作宋」之兩說相持，
而 L5 取了折衷。折衷不是據——本輪已查實其中二人折衷得不對：

- `hixhd2h9bg68` **郭茂倩** →「宋末元初」。實則北宋 1041–1099（維基百科；元豐七年
  為河南府法曹參軍）。四庫、直齋書錄解題（南宋人著錄）、書目答問三源皆作「宋郭茂倩」；
  作「元」者唯《國史經籍志》一源（坑 5 已定其不足據）。名下三書已改 song。
- `hixhd2h9be42` **趙順孫** →「宋末元初」。實則 1215–1276，卒於宋亡（1279）之前，
  無一書成於元（四庫《四書纂疏》提要「宋趙順孫撰」，引黃溍《阡表》）。名下五書已改 song。

二人皆是「名下 work 只落一桶」那 28 個裡的。

## 判準

`dynasty_basis` 以「L5 斷代歸一」起首者，其末句之「確證」一概不作數，須另尋獨立佐證：
生卒年、四庫提要之「宋某某／元某某」、同人名下他書之**真**期分布、南宋人所著之志
（直齋書錄解題、崇文總目）著錄其人。**尤須警惕**：作「元」之單一來源若是
《國史經籍志》或《補遼金元藝文志》《元史藝文志》，其代不足以與四庫相抗——
後三者例收宋末諸家入元（本輪《愛日齋叢抄》《四書纂疏》皆此病），與坑 5
《國史經籍志》之判準同理，建議併入坑 5 或另立一條。

## 掃法

```python
# entity 側
db = e.get('dynasty_basis') or ''
if db.startswith('L5 斷代歸一'):
    per = Counter(IW[x['work_id']]['period']
                  for x in (e.get('works') or [])
                  if x.get('work_id') in IW and IW[x['work_id']].get('period'))
    if len(per) <= 1:      # 「確證」不成立
        report(e)
```
