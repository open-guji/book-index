# 新檢建議：period_upper 之 catalog_bound，其所據之志條須先驗撰人

本道 D 類 23 條掃完，兩個根因各過半，皆可加檢。

## 檢一：catalog_bound 所取之志條，撰人與本條之撰人不相及

D 類 23 條中 **10 條**是這一型：元史藝文志／補遼金元藝文志明著其為元人之書，
而 indexed_by 另掛一條《宋史藝文志》，其撰人、卷數與元條判然不同，
`period_upper_basis` 之 catalog_bound 就取了那條偽志為界，於是 period_upper < period。

例（`d59f2gkm9mo0` 忠孝錄）：元史志「元汪逢辰忠孝錄」／宋志「趙世繁《忠孝錄》五卷趙世逢」。
餘九條見 `known-issues/liaojinyuan-20260906-同題異書之志條待剝.json`。

偽碼：

```python
# 凡 period_upper_basis 以 'catalog_bound' 起首者
src = re.search(r'最緊者為《(.+?)》', w.get('period_upper_basis') or '')
if src:
    ib = next((x for x in w['indexed_by'] if x.get('source') == src.group(1)), None)
    if ib is None:
        report(w, '所引之志不在 indexed_by')            # 見檢二
    else:
        names = {a['name'] for a in w.get('authors') or []}
        blob = (ib.get('summary') or '') + (ib.get('author_info') or '')
        if names and not any(n in blob for n in names):
            report(w, '界志之條不含本條撰人之名')        # 同題異書之疑
```
以「界志之條不含本條撰人之名」為徵候即可，不必真判同異——本道十條無一例外。

## 檢二：`period_upper_basis` 所引之志不在本條 indexed_by 之內

`d59f2gg8bjsw`（春秋精義）之 period_upper_basis 稱「最緊者為《崇文總目》（宋王堯臣等（1041））」，
而本條 indexed_by 唯《元史藝文志》《經義考》二源，**並無崇文總目**。
是引不存在之著錄為據，與坑 1 第三型同構，只是坑 1 在 period_basis、此在 period_upper_basis。
上列偽碼之 `ib is None` 一支即此。

## 檢三：「上限 X 覆驗不相斥」而 X 實早於 period

`d59f2gizl0jk`（草窗詞）period_basis 作「據撰人朝代「宋末元初」；**上限 song 覆驗不相斥**（2026-08-24 R2）」，
而 song 早於 liao-jin-yuan，實已相斥——該次 R2 覆驗之比較方向反了。
同式者本道另見 `d59f2gezddkw`（韜珠秘訣）「上限 song 覆驗不相斥（2026-08-24 R2）」、
`d59f2gkogagw`（五經對訣）「上限 sui-tang 覆驗不相斥（2026-08-22 C1）」、
`d59f2gfpwjr5`（博異志）、`d59f2gf91qf4`（漢書音義）同。**五條皆是真斷代錯**，無一是假陽性。

偽碼：`period_basis` 含「上限 (\w+) 覆驗不相斥」而 `ORD.index(該值) < ORD.index(period)` → 報。
這一檢與 D 類重疊，但它抓的是**留下自白的那一批**，準確率應近 100%，可作 D 類之高信子集先修。

## 檢四（可併入坑 5）：撰人姓名之首字被剝作朝代

本道本批得二例，皆「元」字：
- `d59f2gn6cmww` 行要備急方——宋志「**元希聲**《行要備急方》二卷」、國史志「（**元希聲**）」，
  庫中作 authors[0].name「希聲」、dynasty「元」。姓元。
- `d59f2gmfi874` 神異書——宋志「**元真子**《神異書》三卷」、國史志「（**元真子**）」，
  庫中作 name「真子」、dynasty「元」。元真子即玄真子，唐張志和之號。

二書皆見《崇文總目》（1041），斷非元人所撰。與坑 5 型一（「秦再思」之秦）同構，
惟坑 5 舉的是秦、漢，這裡是**元**——遼金元桶尤易中此，因「元」既是姓又是本期之代。
判準：`authors[i].dynasty` 之值若與 `indexed_by` 之 summary／author_info 中緊接題名前之字相同，
且去之後所餘之名只二字，宜疑其為姓（或名號之首字）。
建議併入坑 5 作第四型「本期之代字即姓氏（元／宋／金／唐皆有此姓）」。
