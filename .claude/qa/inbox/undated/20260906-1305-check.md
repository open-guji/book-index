# 《國史經籍志》括注取作撰人：全庫 3,993 條，多數是對的，錯的只能逐條讀

報一個**不要**全庫機械處分的類——免得別道看見形狀就一鍋端。

## 徵候

焦竑《國史經籍志》著錄作「《書名》N卷（小註）」。匯入時一律取小註為 `authors[0].name`，
並各為之立 entity。全庫 `authors[0].name == indexed_by(國史經籍志).author_info` 者 **3,993 條**：

| period | 條 | | period | 條 |
|---|---:|---|---|---:|
| song | 951 | | nanbeichao | 328 |
| **none（本道）** | **851** | | jin | 220 |
| sui-tang | 711 | | liao-jin-yuan | 128 |
| ming | 510 | | 其餘六期 | 294 |

其中所繫 entity 名下唯此一書者 1,321 條。

## 判準：**不可一概撤**

抽讀之下，絕大多數括注**是真撰人**——東方朔《海內十洲記》、蔡邕《月令章句》、鄭玄《儀禮音》、
魏伯陽《龍虎丹訣》、魚豢《魏略》、陸機《吳章》、皇甫謐《逸士傳》、摯虞《文章流別志論》……
故此非缺陷之類，只是**其中夾著一小撮不是人名的**。真偽之別只能讀其括注之文義：

- **內容之註**：「記唐十五事。」（《集說》）、「張籍等十人詩」（《垂風集》）——帶句號者尤明
- **附刻之註**：「瑤識三十論附」（《成唯識寶生論》，「瑤」蓋「唯」之訛）
- **存佚／卷數之註**：「卷亡」「四十三圖附」（本道批二已撤）
- **形訛之真名**：「隂長主」實陰長生、「賀易」實賀瑒——**這一型撤不得，要正**

本道 851 條中，H 檢撈出 326 條可疑，逐條讀後：312 條是**真名而含中文數字**（張三丰、楊一清、
柯九思、胡三省、劉三吾、徐一夔，及日本人名 曲直瀨道三、竹內楨十郎、添田壽一……），
真缺陷只 14 條，本批已處分 12（撤 5、正名改繫 2、剝「等」6、分拆 1），
餘 22 條之括注既不成人名亦不成可解之語，形不可辨，記 known-issues
`undated-20260906-國史經籍志括注非人名二十二條.json`（附各條 id、題、括注原文與所繫 entity）。

## 給協調者的三個建議

1. **H 檢之噪音**：`ODD_RE` 把中文數字一概當可疑，於是 96%（312/326）是假陽性。
   建議把「含中文數字」與「首字為虛詞／含標點／尾為量詞」分開報——真缺陷全在後者。
2. **假 entity 之隔離**：這一族最實在的害處是**每條各生一個假 entity**
   （`hixhd2h9bl…`／`hixhd2h9bm…` 一段幾乎全是），污染人物庫與 F／H 之計數。
   即使一時不能對校整理本，宜給「只繫一書、名不成人形」者另立 `subtype: unverified` 與真人相隔。
3. **要正不要撤**：形訛之真名（陰長生、賀瑒之類）撤之即失，須以他志相校而後正。
   本道之法：同條若另繫他志（新唐志／宋志／崇文總目），先以他志之文相校；只此一源者才記疑。
