# 新型缺陷：一 Work 之 indexed_by 誤植兩部不同書之著錄（非卷數異文，是根本異書）

補 J 類（description 全缺）之際，讀多源著錄全文時發現：部份記錄之 indexed_by
**不是同一書之卷數異文，是兩部完全不同書被誤合成一條**——判準不是卷數不同
（志書傳抄卷數本多歧異，常態），是**撰人、時代、內容明顯牴牾**。

## 本道所見 3 例

- `d59f2psgsem9`《千金方》：隋志／新唐志范世英三卷 vs 宋志／崇文總目**孫思邈三十卷**
  ——孫思邈《千金方》是醫學史地位極重之名著，與范世英之書斷非一書。
- `d59f2q50gs8y`《外國傳》：隋志釋曇景五卷 vs 舊唐志釋智猛一卷——南朝二僧各自西行
  傳，非一書。
- `d59f2pwuqha9`《名山記》：明史藝文志何鏜十七卷（增輯本存今） vs 補晉書藝文志／直齋
  **符秦王嘉一卷**（即《拾遺記》第十卷別行本）——早六百餘年之異書。

## 掃法建議

三例共同徵候：**indexed_by 中有明確撰人之節，其撰人在庫中另有名望較著之獨立條目
（或該撰人是史上知名人物），而本條之 authors 卻記另一人**。可掃：

```python
# 對每條 work，取 indexed_by 各節之 author_info／summary 中抽出之撰人名
# 若某節撰人 X 與本條 authors 全不同，且 X 在全庫別處有 ≥3 部作品之獨立 entity
# （示其為確有其人、非泛稱），而卷數又與本條相差懸殊（如 3 vs 30），高度可疑
```
