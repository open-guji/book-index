# 坑：save_item 存檔時去空格去標點，卻不回寫索引 path——index 缺記錄檔

`24a5efac86`／`a997c56842`（晉志 source 綴撰人）之提交自陳「10 個檔名之變乃 save_item
去空格去標點所致（如「易繇陰陽卦 汲冢撰」→「易繇陰陽卦汲冢撰」），非刪除」，
但只改了檔名，**未同步索引之 `path`**，遂令 `verify.py` 報「索引檔缺記錄檔」。

現況（origin/main 頭）：**52** 條，其中 **jin 14、none（undated 道）10**——本道所報之
`.claude/qa/known-issues/undated-20260906-補晉志HBCC幽靈條三則.json` 三條
（`d59f6ssrrvbk`／`vkk`／`vm7`）即在其中，該提交本身亦已知之並另記於
book-index-draft／known-issues，可互證。

判準：`save_item`（或其呼叫者）去標點存檔時，必須同時以 `jio.update_index` 或
`reindex.py` 回寫該記錄之索引 `path`（與 `title`，因檔名亦含題名）。

本道核過：現存之 works 索引漂移、entity 索引漂移皆 0（本道所改者索引俱已同步）；
懸空引用 16 條、entity.works 懸空 94 條，經查全屬 jin／nanbeichao 兩道（jin 15、
nanbeichao 1、jin 之 entity.works 懸空 94），非 undated 道，本道不動，僅記此坑。
建議協調者以 `reindex.py` 全庫回掃一次 path／title，或請該提交之作者代修。
