## 三、本道流水线现状（不是设想，是已经在跑的东西）

- **OCR**：31 页 300dpi，PaddleOCR `chinese_cht`，CPU 约 68 秒/页，已完成 20/31。
- **大小字切分靠量图，不靠猜**。实测这套排版（300dpi）：
  - 大字：字距 **46.5px**、墨迹垂直跨度 **≈41px**
  - 小字：字距 **33.2px**、墨迹垂直跨度 **≈26px**
  - 标点被挤压成 **≈0.42 em**（这条是靠逐字量墨迹块间距量出来的，不量就会系统性错位）
  两个字号跨度 41 : 26，中间毫无重叠，**阈值 34px 一刀切干净**。
  再用 DP 把「每字的 x 位置」与 OCR 文本对齐（状态＝已排字数×其中大字单位宽度，
  可精确求解），避免贪心逐字累加造成的漂移。
- **文本规则吸附**：把 DP 偶尔多吞一字的边界拉回到「`某曰：`」与「N篇/卷」处。
- **校記**：靠找页面下方那道横线（实测 p024 在 y＝2001）分区，`①` 起头者另立。

**当前 20 页已切出 234 个元素**：條目 185／小序 24／凡…家…篇 11／校記 10／标题 4。

样例（汉志 p5，全部由图片墨迹高度判定，非人工标注）：

```
[entry] 尚書古文經四十六卷
          ·〈班固自注〉: 爲五十七篇。
          ·師古曰: “孔安國《書·序》云：凡五十九篇，爲四十六卷。…”
[entry] 周書七十一篇
          ·〈班固自注〉: 周史記。
          ·師古曰: “劉向云：周時誥誓號令也，蓋孔子所論百篇之餘也。…”
[entry] 議奏四十二篇
          ·〈班固自注〉: 宣帝時石渠論。
          ·韋昭曰: “閣名也，於此論書。”
```

这正是补录道任务书 §一 讲的那条硬判据——**班固自注无引导语、颜注有 `師古曰：`**——
只不过本道是**先按字号切开、再按引导语归属**，比只按引导语切多一层实物依据：
`議奏四十二篇` 那条，`宣帝時石渠論。` 与 `韋昭曰：…` 在影印本上是**同一个小字号**，
只靠引导语能分对，但**分不出「宣帝時石渠論」到底属不属于志文**——是字号之外的行内空白
与它紧接篇数的位置定的性。两条判据互相印证，本道两条都留在数据里。
