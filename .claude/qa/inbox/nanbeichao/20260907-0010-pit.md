# 急：scan.py 現在全庫皆跑不動——一條 description 存了字串而非物件，M 類崩潰

`python3 .claude/qa/scan.py`（不論 --period 為何）現在對**全庫**皆拋出：

```
File ".claude/qa/scan.py", line 590, in run_checks
    t = ((w.get('description') or {}).get('text') or '')
AttributeError: 'str' object has no attribute 'get'
```

肇因：`d59f28k3vbwl`（period=jin，非本道，屬 weijin 道）之 `description` 欄存的是
**純字串**，不是 SCHEMA 所定之 `{"text": "...", "sources": [...]}` 物件：

```json
"description": "《神仙服食藥方》十卷，晉抱樸子撰。《隋書經籍志》、《舊唐書經籍志》、《新唐書藝文志》、《補晉書藝文志（黃逢元）》所著卷數一致（十卷）。"
```

**在此修好之前，全庫任何一道皆無法跑 `scan.py`**（M 類第 590 行無條件假設
`description` 是物件或 None）。

兩種修法皆可，擇一：
1. （治標，一次性）把 `d59f28k3vbwl` 之 `description` 改回物件形式
   `{"text": "<原字串>", "sources": [...]}`（屬 weijin 道之記錄，非本道之權，或協調者代修）；
2. （治本）`scan.py` 第 590 行改為容錯：
   `desc = w.get('description'); t = desc.get('text','') if isinstance(desc, dict) else (desc or '')`
   ——即使個別記錄違反 schema，掃描本身不應崩潰。

十九之後之現狀，待此修好即補掃。
