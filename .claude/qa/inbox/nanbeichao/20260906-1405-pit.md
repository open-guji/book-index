# 坑：《補南北史藝文志》「深覈·撰人異稱」寫進 ai_note 的「同指一人」多是假的（全庫 163 例，nanbeichao 151）

2026-09-05《補南北史藝文志》（徐崇）入庫之後，其「深覈」一步在 163 個 work 的 `ai_note`
末尾追加了形如下句的段落：

> 2026-09-05 《補南北史藝文志》深覈：撰人異稱——本志作「X」而庫中作「Y」，同指一人。
> 本志用字與庫中不同，非別為一人。

**這些「同指一人」多數是假的**，X 與 Y 是兩個不相干的人。掃法（偽碼）：

```python
pat = re.compile(r'撰人異稱——本志作「([^」]*)」而庫中作「([^」]*)」')
for wid, ie in IW.items():
    for m in pat.finditer(json.load(open(ie['path'])).get('ai_note') or ''):
        x, y = m.group(1), m.group(2)
        if not (set(x) & set(y)): report(wid, x, y)      # 全無共字者尤可疑
```

**計數（2026-09-06，origin/main）**：註記共 **163**（nanbeichao 151、sui-tang 12），
其中 X 與 Y **全無共字者 101**。

真假並存，不可一刀切：
- 真：`d59f2851o4ch` 洞林「元帝／蕭繹」、`d59f99gqc26b` 正序「蕭統／昭明太子」
  （帝號、封號與本名，確是一人）。
- 假：`d59f287ki6f4` 宋書「陸澄／沈約」；`d59f9c0uwhs2` 後漢書注「吴均／蕭方等」
  （本條 indexed_by 自引「按《南史》方等傳：注范曄《後漢書》未就」，明是蕭方等）；
  `d59f99gogmx9` 老子義「張譏／文帝」；`d59f9c0t12iu` 禮論「范岫／文帝」；
  `d59f284xasqt` 孝經義記「蕭巋／沈文阿」——此條尤險：其註不止斷言同一人，
  還編出一段像模像樣的考證（「庫條撰人正作蕭巋，且其《補周書藝文志》著錄語……全同」），
  而本條 indexed_by 之《補陳書藝文志》《補南北史藝文志》兩節皆明作「沈文阿撰，見《南史》本傳」。

**徵候**：X 是《補南北史藝文志》同類目中鄰近另一行之撰人——像是逐行比對時錯了行，
而後把不合之處寫成「異稱」。同批另有「卷數異文」「撰人跨代」等註記，
`d59f9c0t12iu` 禮論之「撰人「文帝」跨代……Work 從書之代、entity 從人之終，不必強同」
即是把一個真誤繫（宋文帝之書繫到梁簡文帝）說圓了過去（本道已改繫，見複查五）。

**害處不在數據而在賬**：這些條之 `authors`、`period` 多半仍是對的，壞的是 `ai_note` 裡
留下 163 條假的身分斷言。後手若據之併 entity（「既云同指一人」），就會把兩個人併成一個——
正是 skill〈磁鐵與合併陷阱〉所戒。愈早劃掉愈好。
