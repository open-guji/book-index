O 類現只掃 `dynasty == '元末明初'` 且生卒相斥者。ming 之 C 類逐條讀畢，發現同一型缺陷
戴著別的標籤，O 掃不到：

  此二號屬明末臨濟宗僧漢月法藏（1573–1635），非唐賢首法藏（643–712）

## 偽碼

```python
DYN_SPAN = {'先秦':(-2000,-221),'秦':(-221,-206),'西漢':(-206,9),'東漢':(25,220),'漢':(-206,220),
            '魏':(220,265),'西晉':(265,317),'東晉':(317,420),'晉':(265,420),
            '南朝宋':(420,479),'南朝齊':(479,502),'南朝梁':(502,557),'南朝陳':(557,589),
            '隋':(581,618),'唐':(618,907),'五代':(907,960),
            '北宋':(960,1127),'南宋':(1127,1279),'宋':(960,1279),'遼':(916,1125),'金':(1115,1234),
            '元':(1271,1368),'元末明初':(1300,1420),'明':(1368,1644),'明末清初':(1580,1700),'清':(1644,1912)}
def dyn_year_clash(e):
    lo, hi = DYN_SPAN.get(e.get('dynasty'), (None, None))
    if lo is None: return False
    b, d = e.get('birth_year'), e.get('death_year')
    return (b and b > hi) or (d and d < lo)      # 生於代末之後，或卒於代初之前
```

全庫一掃即知規模。判準與 O 同：**生卒是硬據，dynasty 多是派生**（cbdb index_year、
author_propagation、L5 歸一），相斥時從生卒。無生卒者退而讀著錄之字里官歷。
