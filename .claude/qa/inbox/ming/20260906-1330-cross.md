# 跨道二事：解繫後遺之 entity 代，與一書兩收九組

## 一、L 類解繫 31 條（已推 main）

ming 道 L 類（孤雁）57 條逐條讀畢：**誤繫 31、本時期常態 16、重出或 period 可議 10**。
31 條之繫連，其由皆是「同名唯一」「CBDB auto/pending_accept」「代相鄰者補繫」，
無一出於讀著錄；而《千頃堂書目》《經義考》之小注恰恰備載其人字里官歷，一驗即破：

- 《春秋錄疑》繫**宋真宗**（entity 別名如此），而四庫「明趙恒……嘉靖戊戌進士」
- 《古今詩文資䝉》繫**淮南王劉安**，而千頃堂「字元静，開封人，永樂癸夘舉人」
- 《君子堂日詢手鏡》繫**西晉王濟**（字武子），而千頃堂「字伯雨，烏程人，嘉靖中貢士」
- 《鳳臺貴竹東屯南遊諸稿》繫**金元僧萬松行秀**（entity cbdb_source 自書「pending_accept: 元萬松行秀禅师」）
- 《鹵簿圗》繫**元曾巽申**（繪《大駕鹵簿圖》者，1282–1330），而千頃堂「永樂人，成祖時為嚴州教授……亦軒先生」

已解者作品側之名與代不動，entity.works 同步去其回指，據悉錄於 `authors[].name_basis`。

## 三、一書兩收九組＋period 誤一條

見 `.claude/qa/known-issues/ming-2026-09-06-明刊前代書之重出待併九組.json`。
成因一律是：**撰人為元（或清）人，而明刊本（明鈔本）之著錄另立一條，落入 ming 桶**。
《黃楊集》／《棲碧先生黃楊集》、《原機啟微集》／《元機啟微》、《圭塘疑乃》／《圭塘欸乃集》、
《雅論》／《雅倫》、《韓氏遺書》／《韓信同遺書》、《詩疑大鳴録》／《詩疑大鳴錄》、
《四書集說啟蒙》／《學庸集說啟蒙》、《唐詩合選》／《唐音遺響集注》，
並《古今書史㑹要》之 entity「陶九成」＝「陶宗儀」（九成即其字，二 entity 名下之書一一相重）。
併條與併人皆跨 ming／liao-jin-yuan／qing 三道，候協調者排。

## 四、可加之檢（建議）

L 類現只報「n−1 同而恰一異」。上列九組之徵候是另一型，值得單列：
**同一 entity 名下，二 work 之題名正規化後相含或差一字，而 period 不同** ——
這正是「明刊前代書」所生之重出。偽碼：

```python
for e in entities:
    ws = [IW[x['work_id']] for x in e.get('works') or [] if x['work_id'] in IW]
    for a, b in combinations(ws, 2):
        if a['period'] != b['period'] and title_overlap(a['title'], b['title']) >= 3:
            yield (e, a, b)
```
