# 掃法：H 類之「名含數字」一則，在 ming 道假陽性率 ~92%

`scan.py` 之 `ODD_RE` 含 `[0-9〇一二三四五六七八九十百千]`。明人之名多用排行字，
於是 ming 之 H 類 267 條中，**257 條是被數字一則掃中**，而其中絕大多數是真名：

> 徐三重 12、楊一清 12、劉三吾 12、王九思 10、瞿九思 10、錢一本 8、沈一貫 7、何三畏 6、
> 徐一夔 5、張九韶 4、蔣一葵 4、孫一元 4、孫一奎 4、侯一元 4、馬一龍 3、沈一中 3……
> 韓千秋、彭百煉、謝五娘、張三豐、孫七政、李如一、朱一是、蔡復一、曾三接、婁九成 各 1–2

148 個相異之名中，經逐條裁定，**真缺陷 22（已修 12、記 known-issues 10），假陽性 126**。
以條數計：267 → 真 22、假 245（92%）。

## 建議之收窄

數字一則若要留，宜只掃**數字出現在名之首尾且與姓不成詞**者，或改為白名單式：

```python
# 排行字在名中（第二、三字）者是明人常態，不報
NUM = '〇一二三四五六七八九十百千'
def odd_num(nm):
    if not any(c in NUM for c in nm): return False
    if 2 <= len(nm) <= 4 and nm[0] not in NUM and nm[-1] not in NUM:
        return False          # 楊一清、劉三吾、徐三重、孫一奎……
    if len(nm) >= 2 and nm[-1] in NUM and nm[0] not in NUM:
        return True           # 「張九一」「趙一元」仍可疑者少，暫報
    return True               # 「一元」「三江」「惟一」等以數字起者，多是僧號／殘名，報
```

真正抓得住 ming 之缺陷者，反是另外幾則（本道所修者皆出此）：
`拆字描述式` `[A+B]`／`《…》`／`?`／`□`；`身分前綴` `^(西洋人|泰西|西洋|大學士|太監|釋)`；
`役字結尾` `(撰|注|編|輯|訂|評|纂|修)$`；`帝王稱謂` `^(明太祖|太祖|世宗|神宗|…)`；
`括號按語` `（.*）$`。建議把數字一則降權，把上五則單列。

## 另補一則新檢（拆字與缺字之描述式）

```python
CJK_PLACEHOLDER = re.compile(r'\[[^\]]+\+[^\]]+\]|《[^》]{1,3}》|[?？□]')
# 例：祁承[火+業] → 祁承㸁（U+3E01）；徐? → 徐𤊹；skill 所舉之 徐《火勃》、顧《山介》、齊《臣灬》
```
ming 道以此法修得二條（d59f2niw3htt、d59f2nf9b2f4），二者**改名前撞庫皆撞到既有之正主**
（hixhd2h9bnt3 祁承㸁、hixhd2h9bnpa 徐𤊹，後者之 alt_names 且早載「徐《火勃》」一形）——
是可自動化之高收益一則。
