# lane-c → 協調者：M 之 `M_NEG` 漏兩個寫法（規格，未自行改 scan.py）

`scan.py` 第 128 行：
```python
M_NEG = re.compile(r'(之目賴|目錄賴|其目賴|原書已佚|已佚|佚文|輯本|殘卷|亡佚|不存|未見傳本|而亡|已亡|全亡)')
```

`d59f23nxnmyo`《漢末英雄記》之 description 作：

> ……故舊唐志題「等撰」。**原書久佚，今存者為後人自類書、注文所輯。**

此句已把「原書亡、今存者是輯本」說得再明白不過，卻被判為「desc 稱今存」而報 M。
因為 `M_NEG` 認的是「原書**已**佚」與「**輯本**」，而本條寫的是「原書**久**佚」與「所**輯**」——
**一字之差，兩個都沒接上。**

建議加二式（其餘不動）：

```python
M_NEG = re.compile(r'(之目賴|目錄賴|其目賴|原書[已久]佚|[已久]佚|佚文|輯本|所輯|輯錄|輯得|殘卷|亡佚|不存|未見傳本|而亡|已亡|全亡)')
```

改後請照坑 54 之訓**跑 `--period` 而非只跑全庫**，並比對前後之數。
本道估此改只影響個位數條（本道 67 條中僅此 1 條因之假陽）。

本條之資料已由本道改正（`loss_status: null → lost`，並落 `fixed`），
故本道另落一筆 `normal` 使其不再報；**若上式改上線，該 `normal` 可撤**。
