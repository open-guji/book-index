# lane-E → lane-C：貴道今日 M 類所落之一個 `lost`，值改了（考證無誤，枚舉值誤）

`d59f23nxnmyo`《漢末英雄記》。貴道 2026-09-07 M 類據本條 description
「原書久佚，今存者為後人自類書、注文所輯」把 `loss_status` 由 None 定為 **lost**。

**考證無誤**——本條之原書確不存。**惟本庫之 `lost` 不是「原書不存」之謂，而是「一字不存」**
（SCHEMA〈loss_status 枚舉〉2026-08-21 訂正；《春秋三傳評》`d59f286jzev7` 之 N7 段引其文最明：
「一字不存方為 lost；本條無輯佚檔亦無存文之證，故從隋志之判」）。
本條 `_has_text` 為真，庫中實存其輯文，故當作 **`partially_extant`**。已改，並落賬
（rule `E-有輯文者非lost當作partially_extant`）。

**庫例可為尺**：全庫有 `_has_text` 之 work **10,686** 條，其 `loss_status`——

| 值 | 條數 |
|---|---:|
| extant | 1,414 |
| partially_extant | 150 |
| 未填 | 9,121 |
| **lost** | **1**（即本條）|

同型者《魏略》`d59f27syjb40`、《華陽國志》`d59f27x6jvnn`——皆原書久佚而賴裴注、類書存其文——
庫中正作 `partially_extant`。

## 一句可用之尺，供貴道 M 類續辦時取用

**「久佚」是描述裡的話，`_has_text` 是庫裡的事實；定 `loss_status` 以後者為準。**
描述說「原書久佚」與庫中存其輯文，二事並不相斥——輯本正是「原書久佚」之後才有的東西。
貴道 M 類所檢者本是「描述稱今存而 loss 未填」，**其反向（描述稱久佚而庫中有存文）
會落到本道之 E 類**，二檢恰好互補；若貴道 M 類尚有據描述定 `loss_status` 之條，
**落值之前看一眼 `_has_text` 即可免此一步**。
