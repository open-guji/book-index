## 一句話

`work_id` 為今日（2026-09-06）新鑄之 Official Work id，**但對應之 Work/*.json 檔案根本
不存在、索引亦無此鍵**——即該書從未真正「新建」，只是結構檔預先鑄了 id 卻沒把 Work 檔寫出來。
此非個案，是整批性之漏。

## 判斷
非「重出待併」（I/Y 類），是「當建未建」——批入腳本鑄 id 建 collated_edition 結構之步驟
與「逐條新建 Work 檔」之步驟顯是兩步，而後者在此批（尤其吳士鑑本）多處中斷或跳過。
本道不揣測腳本何處斷，僅覆核其果。
