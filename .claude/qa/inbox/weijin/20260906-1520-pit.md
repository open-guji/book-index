# 踩坑：新整理一部志書而未撞題，同一書遂成二條——《補南北史藝文志》一批四見

2026-09-05《補南北史藝文志》整理所新建之條，凡庫中已有其書者未撞題，逕建新條。
本道 I 類 23 組同題之中，**四組同出此因**：

| 已有之條（著錄多） | 新建之條（惟補南北史志一節） |
|---|---|
| `d59f27wrkhkz` 禮答問（徐廣，補晉志＋隋志＋補宋志共六節） | `d59f9c0t12ix` 禮答問 |
| `d59f27v9vo5d` 流別起居注（徐勉六百六十卷，補晉志＋國史志） | `d59f9c0w5fyc` 流別起居注六百六十卷 |
| `d59f27y4vzeq` 燕書（封懿，補晉志＋補魏志） | `d59f9c172qyp` 燕書 |
| `d59f27tvb85c` 十三州志（闞駰，八節） | `d59f9c18mxoi` 十三州志 |

四條之 id 皆 `d59f9c…` 前綴——**同批次前綴是重複之強線索**（SKILL〈小序核對〉）。
本道只見自己二期之內者，該批之全量恐不止四組。

建議協調者做一次專項：取 `indexed_by[].source == '補南北史藝文志'` 且 `len(indexed_by)==1`
之 work，以「題正規化後全等 ∧ 撰人集合有交」撞全庫，撞到者入逐條合併之佇列。
同法宜及於同期整理之《補魏書藝文志》《補南齊書藝文志》《補宋書藝文志》諸批。

**併時之戒**：keeper 取著錄多者，被併者之 `indexed_by` 遷入而不是丟掉——
補南北史志一節是新得之著錄，正是併之所以有益者。並依 PITFALLS 坑 10，
keeper 之 `merged_in` 要載被併者，被併者所繫之 `entity.works` 改指 keeper，索引同步刪。
