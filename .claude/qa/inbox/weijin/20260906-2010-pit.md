# 踩坑：新檢 X（撰人切短）於本道二例皆假陽性——書名本三字以上者尤易誤判

X 類（`kind: 撰人切短`）猜「作者名＋書名」之切分點偏前一字，本道抓到二例，
逐一以 WebSearch 覆核，**皆為假陽性**——原分法已對，X 之猜法錯：

1. `d59f27slfcaq` 氏姓論——raw「管寧氏姓論　寧始末具雜傳記類」。
   X 猜「管寧氏／姓論」，實則陳壽《三國志·管寧傳》評語逕載「（寧）著《氏姓論》以原本世系」——
   書名本是《氏姓論》三字，「管寧」是撰人，現有之切分（管寧／氏姓論）已對。

2. `d59f27t79ybk` 昕天論——raw「姚信昕天論」。
   X 猜「姚信昕／天論」，實則《昕天論》是姚信（三國吳）本人所立之宇宙論一家，
   與蓋天說、渾天說、宣夜說、穹天論、安天論並列古代六家天說之一，書名本是《昕天論》三字，
   「姚信」是撰人，現有之切分（姚信／昕天論）已對。

**共同病徵**：二例之「書名」皆三字（氏姓論、昕天論），而 X 之猜法把書名縮成二字
（姓論、天論）、撰人加長一字——猜法之偏向似是「書名傾向二字」，而漢晉子部論體
（XX論）之書名實三字者甚多（氏姓論、聲無哀樂論、昕天論、才性論、聲類論……），
與集部書名（多二字如「XX集」）之切分習慣不同，X 之校準或誤把集部之慣性套到論體。

判準建議：X 之猜法宜先撞庫或撞史傳原文（如本例之《三國志》本傳逕引書名）——
凡「書名」猜法之候選詞可於全庫或 ctext 撞得逐字相同之著錄語（如「著《氏姓論》」
「立昕天論」），且撰人猜法之候選詞（如「管寧氏」「姚信昕」）**不成詞、不似人名**者，
偏向原分法而非猜法。本道二例皆屬此類：猜出之「撰人」候選「管寧氏」「姚信昕」既非
習見人名亦非成詞，而猜出之「書名」候選「姓論」「天論」雖成詞但過泛，二者相權，
原分法（三字書名）更可信。
