# 新檢：entity 之 primary_name 帶著錄語之贅（役字／官銜／身分／朝代）

本道 F 類 64 條中，十七條之病不在 work 而在 entity——其 `primary_name` 是自 work 之
`authors[].name` 直取而未去著錄語之贅：

| 型 | 例（entity id） |
|---|---|
| 役字 | 陳壽**定** `hixhd2h9bktx`／葛洪**譯** `hixhd2h9bkud`／陳卓**記** `hixhd2h9bkte`／鳩摩羅什**課** `hixhd2h9bksc` |
| 官銜 | **郎中**程韶 `hixhd2h9bksv`／**陵相**孔衍 `hixhd2h9bnpw`／**太史令**吳範 `hixhd2h9blsq`／**太史令**韓楊 `hixhd2h9bktf`／**趙王倫舍**（「趙王倫舍人」之殘）`hixhd2h9bktd` |
| 身分／朝代 | **道士**王浮 `hixhd2h9bkuc`／**姚秦釋**僧叡 `hixhd2h9bksm` |
| 形訛 | 蔡護←蔡謨／王陽←王隱／虞豫←虞預／楊義←楊乂／董助←董勳／徐瑜宜←徐宣瑜 |

**要緊處**：這些 entity 多與正主並存（陳壽 `hixhd2h9bi85` 十書、葛洪 `hixhd2h9bet2` 六十五書、
孔衍 `hixhd2h9bhrz` 十九書……），壞名者名下多只一二書。scan F 抓得到（撰人名不在 entity 之名），
但**報表看不出「正主就在隔壁」**，逐條讀才知。建議 scan F 之明細加二欄：

```python
# F 明細加：庫中有無與 work 之 authors[].name 全等之別一 entity，及其 works 數
cand = [e for e in ENT_BY_NAME.get(a['name'], []) if e != a['entity_id']]
row['same_name_entity'] = cand
row['same_name_nworks'] = [len(ENT[c].get('works', [])) for c in cand]
row['cur_nworks']       = len(ENT[a['entity_id']].get('works', []))
```

有 `same_name_entity` 且 `cur_nworks` 遠小於 `same_name_nworks` 者，幾乎一律是壞名之條，
可作零判斷批次之候補（仍須人看一眼役字與官銜之別）。本道十九條依此法改繫，無一例外。

**另一半是反面**：`cur` 是正主而 work 側之名帶贅（王弼**輔嗣**、陸績**公紀**＝名＋字；

「王　約」＝全形空格），這一半**不是缺陷**，依 SKILL 坑十著錄之名照舊，不當改。
