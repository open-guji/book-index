# 踩坑：pushmain.sh 之 resolve_conflicts 缺 `git add`，取己方／彼方後仍判「未解」

## 情況

本道推送時撞上上游大宗入庫（`47d4a0ae60` 補晉書經籍志·吳士鑑，2673 檔）之 6 處 Work 衝突。
`pushmain.sh` 之 `resolve_conflicts()` 對非索引檔案執行 `git checkout --ours -- "$f"`
（見腳本 22 行），但**未接著 `git add "$f"`**——`git checkout --ours` 只更新工作區內容，
索引（暫存區）仍留衝突狀態；其後之覆核 `git diff -z --name-only --diff-filter=U` 仍讀出這 6 檔，
判定「解衝突未竟，尚餘 6 檔未解 — 中止，勿硬提交」，腳本正確地不誤推，但**每次撞這類衝突
都會卡住，需手工介入**。

## 建議之修

`resolve_conflicts()` 之 while 迴圈內，`git checkout --ours/--theirs -- "$f"` 之後補一行
`git add -- "$f"`：

```bash
    case "$f" in
      index/*) git checkout --theirs -- "$f" && git add -- "$f" || echo "取彼方失敗：$f" >&2 ;;
      *)       echo "非索引衝突，取己方：$f"; git checkout --ours -- "$f" && git add -- "$f" || echo "取己方失敗：$f" >&2 ;;
    esac
```
