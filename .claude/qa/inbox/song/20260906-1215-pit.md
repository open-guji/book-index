# 「誤建 entity 併治」之反噬：dynasty=None 之條被併入同名之北朝人，宋人之書隨之易代

2026-09-05 有一輪「誤建 entity 併治」，其理曰：「前輪整理腳本遇庫中同名而 dynasty 為 None 者，
誤判『代不相容，別是一人』而別建；然 dynasty=None 乃**未考定**，非『不相容』，不可據以斷為二人。」
——此理不誤。**然併之前未驗其名下 work 之代**，於是併出了 skill 坑 4（同名二人共一 entity）。

尤可注意者：劉懋、張洪二 entity **本是 2026-08-24「同名異人分立」專為宋人所立之條**
（其時 dynasty=song，所據正是上表末欄之行實）；併治與新志收書之後反成北朝人，
分立時所立之據被覆蓋——**一次正確的分立被一次機械的合併抹掉**。

## 判準（可加進 PITFALLS）

凡合併同名 entity（不論理由是「dynasty=None 非不相容」還是別的），
**合併前必列兩造名下全部 work 之 period**；跨兩代以上者不併，或併後即分。
`dynasty=None` 不是合併之許可，只是「不足以斷為二人」——不足以斷分，同樣不足以斷合。
