# 《國史經籍志》括注之撰人名多形訛——本道與 qing 道各自撞見，宜寫進坑本

本道批四於 song 桶得五條（見 `20260906-1320-check.md`）：
語六昌←程大昌（演繁露）、三庭嵇←王應麟（玉海）、三趙←洪邁（容齋隨筆）、
眞德四秀←真德秀（四書集編）、六應民←林應辰（龍岡楚辭說）。

批五清單向邊時，又見 **qing 道獨立撞見同型二條**，其 work 之 period 皆 song：
`d59f2mpvncap`《事物紀原類集》國史志作「（**高里**）」而實**高承**（北宋）；
`d59f2mptrx1d`《燕翼貽謀錄》國史志作「（**王林**）」而實**王栐**（宋）。
二者之 work 側已由 qing 道改繫正主，而 entity 側之回指未撤，成單向邊（坑 12），
本道已撤（其 work 屬本道之期）。另二條同批：《春秋統例》（朱臨）、《春秋義》（王棐），
qing 道判 CBDB 之配為同名異代而解繫，entity 回指亦未撤，一併撤之。

## 何以成群

此四訛名（高里、王林、朱臨、王晫）另有一共相：**皆被 CBDB 配上了清人**
（高里 cbdb 387123 鑲黃旗、王林 57154 漢軍正紅旗、朱臨 73913 長洲、王晫 69366 仁和）。
訛名短而常見，於是在 CBDB 六十六萬人中總撞得著同名者，而所撞多是清人——
**訛名 × 同名唯一 = 假配**，兩個錯誤互相坐實。

## 判準（建議入 PITFALLS）

凡撰人之名唯出《國史經籍志》括注、而其書別有他源可徵撰人者，**以書求人，勿以名求人**：
先查該書通行之撰人（他志、四庫、維基），再以正名撞本庫索引。
其括注之訛多是形近（程→語、大→六、王→三、應→庭、麟→嵇、洪邁→三趙、承→里、栐→林）
或涉書名而衍（真德秀→眞德四秀，涉「**四**書集編」）。
此志既有坑 5「明焦竑抄撮舊目，其代不足據」，今再得一條：**其括注之撰人名亦不足據**。

徵候可掃：entity 名下唯一 work、該 work 唯《國史經籍志》一源、且 entity 之代與 work 之代遠隔。
本道五條、qing 道四條皆中此式。
