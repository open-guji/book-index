# 新缺陷類：撰人／書名切分之誤（掃法附上，1,102 條待各道核）

## 是什麼

志書著錄之體例是「撰人＋書名⟨小注⟩」，匯入時要在二者之間切一刀。切錯一格就憑空
造出一個人，而拼起來與原文一字不差：

| 著錄原文 | 現切 | 應切 |
|---|---|---|
| 徐允禄思勉集 | 徐允＋《禄思勉集》 | 徐允禄＋《思勉集》 |
| 葉文莊公菉竹堂書目 | 葉文＋《莊公菉竹堂書目》 | （葉盛諡文莊）＋《菉竹堂書目》 |
| 雷伯宗千金寶鑑 | 雷伯＋《宗千金寶鑑》 | 雷伯宗＋《千金寶鑑》 |
| 清丁丙藏編…樓書目 | 丁丙藏＋《樓書目》 | 丁丙＋《八千卷樓書目》 |
| 周鳯翔周文介公集 | 周鳯＋《翔周文介公集》 | 周鳯翔＋《周文介公集》 |

**字串比對查不出**（拼起來一樣），**CBDB 也驗不出**（這輩多是方志別集之作者，
無官無科第，本不在 CBDB 之列——「徐允禄」「王承蕙」在 CBDB 皆查無其人）。
本道是在別的線索上一再撞見它才認出這是一類：卸 CBDB 誤配時撞見丁丙藏、王文，
併書後清單向邊時撞見葉文，朝代衝突逐條裁時撞見徐允、沈弘、王承、劉虞、武舉。

## 掃法

`overview/scripts/cbdb-sync/scan_author_title_split.py`，不需 CBDB 庫。

判準：書名首字 c 若「常入人名而罕冠書名」（用全庫自身統計——c 在 authors 之名中
非首字位出現幾次，對 c 冠於 title 之首幾次），而其前之撰人名恰是二字，刀多半落早
了一格。正反六證見腳本首註。

**判準打磨過三輪，每輪抽二三十條逐條核。假陽性有三類**，各道自己寫掃法時要防：

1. **以字名集**——「夏煜允中集⟨字允中金陵人⟩」，「允中」是其字，《允中集》以字
   名集，撰人「夏煜」本就對。查小注之字號含不含書名首字即可排掉。
2. **齋號被切進書名**——「謙齋存稿」「慎齋稿」「寅軒稿」「如是齋集」「肖徳堂集」，
   首字是齋號之一半。查書名第二至四字是不是齋號用字（齋軒堂山谷溪雲亭樓園庵…）。
3. **地名／通名**——「余鏜良鄉縣志」之《良鄉縣志》是真方志，而「鄉縣志」不成詞；
   「吕騵紹興先達傳」之紹興是地名（小注「山隂人」正合）。

## 一道精度近乎百分之百的正證

**書名以「姓＋字／諡／官名」起頭**：《周文介公集》《何文毅集》《劉忠愍公年譜》
《梁彥國存稿》《吳貞肅公集》——集以其諡、其字、其官命名，書名首字正是撰人之姓。
姓既已在書名之內，撰人那一欄剩下的就不可能是完整姓名。這一檔十條全部確證，
已落盤（正名五人、解繫七書，見同日提交）。各道遇「X公集」「X先生集」形制之書名
而撰人只有二字者，可逕用此證。
