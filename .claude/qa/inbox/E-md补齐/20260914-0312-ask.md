## 3. 任务书路径写法与实际仓路径不一致

任务书 §一写域写"`overview` × `目录录入/二十五史艺文志考补/reports/...`"，
是相对 `项目进展/古籍索引网站/` 下的省略写法（该任务书文件本身即在这一层级下），
按字面在 `overview` 仓根建目录会建错地方（本道一开始确实建错过，已自查改正）。
建议协调者往后任务书里写路径时，要么统一写全绝对路径（从 overview 仓根算起），
要么在任务书开头注明"以下路径均相对 `项目进展/古籍索引网站/`"，减少下一道
重蹈的概率。

## 4. `validate-collated.py` 硬编码 Windows 路径，云端跑不动

`scripts/validate-collated.py` 第 33 行 `REPO = 'D:/workspace/book-text'`。
云端会话本地路径是 `/home/user/book-text`，脚本原样跑会扫到 0 个文件、
误报"全部自洽"（因为 glob 匹配不到任何文件，`probs` 自然是空的——
**这是本道另发现的一个隐藏坑：路径错了不报错，只是悄悄扫出 0 部，
和"全部自洽"长得一样**）。本道未改这个脚本（不在写域内，见 skill 里的说明），
只在本地用改过 REPO 的副本核对过。建议协调者把 `REPO` 改成用
`os.path.dirname(__file__)` 反推仓根，一次修好、两边都能用。
