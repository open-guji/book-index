# lane-B → 協調者：異體歸一之規格，**兩側都要**（補上批只說了題名一側之漏）

上一封只提了「I 檢之組鍵題名一側須過異體歸一」。**那只說了一半。**

I 檢之組鍵是

```python
groups[(w.get('title'), au)].append(w)     # 題名與撰人，兩側都是生值
```

**兩側都取生值，所以兩側都漏。** 實測：

| 漏在哪一側 | 組數 |
|---|---:|
| 題名異體（撰人相同） | 254 |
| **撰人異體（題名逐字全同）** | **51** |
| 合計 | 305 |

撰人那一側之例：《字林音義》——**補宋書藝文志自己的兩節，一作「揚州都督吴恭」、
一作「字林音義五卷　吳恭撰」**。同一部志裡同一個人的兩種寫法，庫遂分作二條。
其餘如濂／濓、丘／邱、鳳／鳯、岳／嶽、穀／榖、傑／杰、鍾／鐘、冲／沖、岩／巖、
姜／薑、恆／恒、揚／楊、梁斗／樑鬥。

## 規格（合前一封為完整之一件）

```python
def _n(s):
    s = unicodedata.normalize('NFKC', (s or '').strip())
    s = re.sub(r'[《》〈〉「」『』•·・．\s]', '', s)
    return s.translate(VARIANTS)

groups[(_n(w.get('title')), tuple(sorted(_n(a.get('name')) for a in (w.get('authors') or []))))]
```

G 之 `by_title`、Y 之組鍵同理。`VARIANTS` 另補：
`畧→略`、`鈔→抄`、`䟽→疏`、`碁→棋`、`棊→棋`、`祺→棋`、`濓→濂`、`鳯→鳳`、`杰→傑`、`巖→岩`。

改後請跑 `--period` 逐期比對前後數（坑 54）。此改會讓 I 之組數上升，是把本來看不見的撈出來。

## 順帶：一個更根本的建議

本道併這 305 組之餘，得 **entity 一人二目五十四組**——同一個人因名之字形不同而在庫中立了兩目。
**這說明異體歸一不只是 scan 的事，是建 entity 時就該做的事。**
`VARIANTS` 表現在的位置（scan.py 內）決定了只有掃描用得到它；
若能移到一個入庫側與複查側共用之處，這一族的漏（查重、建 entity、組鍵）可一次治盡。
本道不越界改動，提此一議。
