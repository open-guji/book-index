## 一、`d59f2psv5bls`「又欒城集」——**幻條，證強**

```

又《欒城後集》二十四卷　又欒城第三集十卷　又應詔集十二卷
```

「又」在《》**之外**，是承前之辭，所承者蘇轍——正題即《欒城集》。
（合本道自宋志所立之判準：承前之又在《》外，題中之又在《》內。

## 二、`d59f2q2vd6o2`「又歷官表奏」——**列為候選，但本道標明其不確**

原文同卷，「歷官表奏」凡四見，其一：

```
蔡襄奏議十卷　倪思奏議二十六卷
又翰林奏草一卷　又歷官表奏十卷
```

依此則本條所承者倪思，正題《歷官表奏》。**但同卷另有**：

```
許敬宗集　歷官表奏十卷　鄭僑　歷官表奏十二卷　周必大
```

即《歷官表奏》一題在此志下**不止一書**。而庫中 `d59f2q1u7xfk`《歷官表奏》jc=10
亦出同一 `source_bid`（`d59f2nl40936`），其 `title_info` 作「《歷官表奏》十卷」（全文），
本條作「《又歷官表奏》卷」（**「卷」前無數，是截斷**）。

二者**或為同一行之兩錄（幻條），或分屬倪思與許敬宗二人之同題書**。
該段文字之底本於撰人置於書名前抑或後**前後不一**
（「蘇轍黃門集」撰人在前，「許敬宗集　歷官表奏十卷　鄭僑」則似在後），
**憑此本斷不下**；本條 authors 空，亦無從以撰人別之。

→ **請 B 道勿逕併**，宜另覈善本或他本之《國史經籍志》。
