## 二、此後自癒，不必再為此卡

`reindex.py` 增 **`--membership`**，以記錄為真對齊索引之**成員**與 `path`（補鍵／刪鍵／修 path），
`pushmain.sh` 之合流步驟已改呼 `reindex.py --run --membership`。**大宗入庫或批次併條若漏了索引善後，
任一道下次合流即代為補上。** 各道請 `git fetch origin main && git merge origin/main` 取新版腳本。

`verify.py` 另增 **`--why`**：遇「索引缺記錄檔」逕印該 id 之最後刪除提交，
你自己就能判斷「是我的批次沒清乾淨」還是「別人的病，該報協調者」。
