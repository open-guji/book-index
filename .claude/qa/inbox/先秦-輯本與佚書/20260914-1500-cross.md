# 34 個新建輯本 Book 缺一個「所屬叢書」的 Collection 可繫——新建叢書級 Collection 不在本道寫域

**給**：總協調者
**發**：先秦-輯本與佚書道

---

## 一、事由

本道為 131 條先秦佚書之輯本情形逐條落賬，其中 34 條判定為「有輯本」並新建了對應
Book 記錄（大多為清馬國翰《玉函山房輯佚書》所輯，另涉孫星衍《平津館叢書》、
孫馮翼《問經堂叢書》兩種）。

依任務書 §三·二判準，Book 建成後 `contained_in` 應繫到其所屬叢書。但覆核時發現：

- 《玉函山房輯佚書》（`d59f2mua7w8y`）、《平津館叢書》（`d59f2mqifnyb`）、
  《問經堂叢書》（`d59f2pzg2fwg`）**庫中皆只有 Work 記錄，沒有 Collection 記錄**。
- `qa_book.py` 之 `CIN06` 檢查明確要求 `contained_in[].id` 須指向一個真實存在的
  **Collection**；指向 Work 會報 FAIL（`contained_in 引用的 Collection … 在兩倉找不到`）。

**本道寫域不含新建叢書級 Collection**（見任務書 §五「不要碰」），故 34 個 Book
暫時**都沒有寫 `contained_in`**，只在 `edition`／`indexed_by` 文字裡註明所屬叢書，
並在各 Book 之 `ai_note` 補一句「所屬叢書庫中僅有 Work 記錄，非 Collection，
contained_in 暫不繫，已出 cross 單」。

## 二、請協調者裁

1. 是否要為《玉函山房輯佚書》等三部輯佚叢書新建 `Collection`
   （`subtype=work_collection`，因目前只有目錄層資訊，無具體版本影像）？
2. 若建，34 個 Book 的 `contained_in` 由誰回填——本道可以做（涉及本道已建之 34 個
   Book，屬本道寫域內字段），還是歸屬版本方向（F）統一處理？

## 三、涉及的 34 個 Book（id 前綴 `98jhh`/`98jhi`，皆本道 2026-09-14 新建）

見本道 `done` 單附表；一個 Work 一個 Book，`work_id` 已正確雙向鏈。

## 四、不影響的部分

- `verify.py --strict` 已過（Work 側 `books[]` 懸空計數為 0，`index/books/*.json`
  已用 `jio.load/save` 補鍵，格式與既有分片一致，diff 最小）。
- `qa_book.py` 對這 34 條唯一的 FAIL 是 `REQ01 resources`——按

  resources，此 FAIL 為機械層之已知假陽性，不算本道之缺。
