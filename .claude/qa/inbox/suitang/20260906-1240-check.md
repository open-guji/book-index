新檢：`period_basis` 自稱「據其 Entity 之 period 傳播」而該 entity 之 period 與本條不同——傳播之基準與其源相牴。

**徵候**：work 之 `period_basis` 含「據其 Entity「X」之 period 傳播」或「entity_propagation」，
而所繫 entity 之 `period` ≠ work 之 `period`。既曰傳播，二者必同；不同即傳播之後有一側被改而另一側未隨。
scan C 類（entity_period）會撈到，但 C 類多為注疏之常態（唐人注漢書），真缺陷埋沒其中；
**以「基準自稱傳播」為篩，可從 C 類裡切出高精度的一小撮**。

**例**（本道批3 已修）：`d59f28n7madg`《孝經釋慧琳注》——basis 作「撰人朝代闕，據其 Entity
「釋慧琳」之 period 傳播」，而 entity `hixhi4q6azo0` 之 period=nanbeichao，本條反作 sui-tang。
同 entity 名下七書六書 nanbeichao。已正為 nanbeichao。

**掃法偽碼**：

```python
for w in works:

```

其餘之異即真缺陷。建議加入 `scan.py` 作 C 類之子項（如 C*），與泛 C 類分列。
