新檢：entity 之 primary_name 帶前綴（官銜／身分／朝代），是 F 類之大宗，且可機檢。

**徵候**：`entity.primary_name` 以官銜、身分或朝代之字起首，而其名下 work 之 `authors[].name`
正是去前綴之名，於是 scan F 報「撰人名不在所繫 entity 之名／別名」——**其實繫得對，錯的是 entity 之名**。
病源：建 entity 時逕取著錄之 author_info 全文為名，未剝黏連（skill〈姓名四種黏連〉）。

**例**（本道批5 已正六個，皆名下唯本道之書、且庫中無同名可撞）：
`道士李沖昭`→李沖昭、`道士史崇`→史崇、`道士李少卿`→**李仲卿**（兼正形訛）、
`郎中馮古`→馮古、`學士竇儼`→竇儼、`南唐劉鶚`→劉鶚。著錄原形一律存 `alt_names[{type:"著錄形"}]`。
本庫既有先例：2026-08-25「孤懸 entity 普查（前綴污染）」去「溧水令沈汾」而存其形。

**掃法偽碼**：
```python
PREFIX = ('道士','僧','釋','沙門','學士','翰林學士','郎中','員外郎','侍郎','尚書','太守','刺史',
          '祭酒','博士','處士','徵士','先生','法師','禪師','居士',
          '唐','宋','漢','晉','梁','陳','隋','元','明','清','南唐','後唐','後晉','後漢','後周','前蜀','南漢')
for e in entities:
    n = e['primary_name']
    for p in PREFIX:
        if n.startswith(p) and len(n) - len(p) >= 2:
            core = n[len(p):]
            報(e.id, n, core, 撞庫=[x for x in by_name.get(core,[]) if x != e.id],
              名下之期=Counter(period of e.works))
```
**處置之三分**（本道所用，建議立為通則）：
1. 無撞庫、名下之書全屬一道 → 該道正名，著錄形入 alt_names；
2. 有撞庫而顯為同一人（同代同書）→ **重出待併**，記 known-issues，不逕改（本道之「南唐何晦」／「何晦」即此）；
3. 有撞庫而顯為異人（代不相及）→ 仍可正名，惟須於 ai_note 明記庫中同名者為誰、須以代覈之
   （本道之「道士史崇」→史崇，庫中別有東漢史崇）。

**另一半：F 類之次大宗是「廟號／尊號／行名之著錄形不在 alt_names」**——
work 作「太宗」「德宗」「則天皇后」「薛登」「張昭」而 entity 作「李世民」「李适」「武曌」「薛謙光」「張昭遠」。
繫得對、名也對，只是 alt_names 缺著錄形。處置：補 alt_names，不動 primary_name（本道批5 補五人）。
