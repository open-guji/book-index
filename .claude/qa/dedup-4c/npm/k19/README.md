# 故宫一号多书（合刻／叢書一册）Book：K19 处理

2026-10-26，接 4c-故宫 batch-01 的「合册待拆」108 个，并扩到故宫全部同类馆藏号。

## 口径（与早稲田 A4 线程的 K19 一致）

K19 原文在 book-index-manager `docs/馆藏资源挂接/规范/口径.md`：一个馆藏实物同册合刻几种书时，资源只挂主书 Work，不往同册其他书上再挂；资源上加 note「合刻本：同册另含《某》《某》（K19，只挂主书）」；只挂、不改 Work，也不因合刻并 Work 或建新 Work。

故宫的落法：

- **Book 不拆，也不为同册其他书新建 Book。** 现库故宫 17,535 个馆藏号对 17,539 个 Book，一直是「一个馆藏号一个 Book」；为同册另几种书各建 Book 会让同一件实物和同一条资源出现在几个 Work 上，和 K19 第一条相冲。
- **主书＝Book 现题名。** 故宫导入时已「同號多書按書名/卷數挑選」定了一种，4c-故宫复核过这 108 个都挂对了。不按「题名第一种」重挑，免得只为口径搬 Book。
- **note 写在 Book 的故宫资源（`npm-rarebooks`，`metadata.item_id`＝馆藏号）上**，题名取故宫著录、去卷数，按著录顺序。Book 自身 revision 升一个小版本。
- 同一馆藏号的多条著录若都是本书（分卷、附录分条），不写。

## 数字（main c5d4e3ecc12）

- 故宫著录 18,396 条、17,576 个馆藏号；一号多条的 529 个，对上 Book 的 528 个（另 1 个是同一号两个 Book）。
- 写 note **233** 个 Book（含 4c-故宫 合册待拆 108 个全部），清单 `plan.tsv`（含改前 sha256）。
- 不写 296 个：同书多条（故宫把一部书的分卷、附录分条著录）。清单 `skip.tsv`。
- 主书认定：题名先繁转简、去卷数后全等；不等时退到互含（僧寶傳／禪林僧寶傳）或同长差一字（辨／辯），且须唯一。
