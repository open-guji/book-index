# 任务：古籍书目同题 Work 逐对判定（只读，不改任何仓库文件）

输入文件每行是一个「同题组」：key（归一题名）、works（每个 Work 的著录：题名、责任者、indexed_by 总目/史志著录原文〔title_info 含卷数，author_info，summary 含总目版本与收藏馆〕、ai_note、所挂 Book 版本）、pairs（待判的对，machine＝机器预判，why＝机器理由）。
请逐对读两侧著录原文，判断这两条 Work 是否同一部著作（同一修次）。只依据所给著录，可辅以可靠的目录学常识（理由里注明「常识」）。

判定码（每对只给一个）：
- SAME：同一部书、同一修次，应合并。需要正面证据：同撰者（或异写可证同人）且卷数相合/一侧缺且不矛盾；或史志书目（千頃堂、明史藝文志、清史稿藝文志等无版本著录）与总目现存本同撰者同题；或同一修重复著录（同年号同卷同馆）。
- C：分立。不同撰者的同题异书；同名异地（地望不同的族谱、不同地方的志）；同地不同修次的方志或族谱（年号/年份不同、卷数悬殊、堂号不同）；原书与注本/续编/节本等层次不同。
- E：同一撰者主持的不同修次（续修、增修、重修），分立但应互链。
- D：证据不足，存疑不并（例如一侧佚名、无卷数无版本可比；或两侧都是「清□□纂修／清木活字印本」这种无年份记录）。

口径要点：
1. 方志：一个修次＝一个 Work；修次年号不同即 C；故宫《善本舊籍》、史志书目录入的无年号条，若撰者同、卷数不矛盾，与总目某修次是同一书 → SAME（注意若同地有多个修次，要能确定对的是哪一修，否则 D）。
2. 族谱/家乘：各修各算一个 Work。地望不同 → C；同地望但年份、卷数或堂号不同 → C（异修/异支）；同年同卷同馆 → SAME；纂修者只录一人不同不否定同一修。佚名「清□□纂修」与具名条，无年份可比 → D。
3. 年谱：同一谱主不同编者 → C（不同著作）；同编者同书 → SAME。
4. 谱录（琴譜、菊譜、印譜等）、非方志的「某某志」（筆記、雜史等）：按普通著作，同撰者同题且无反证 → SAME；不同撰者 → C（除非有「一名」「即」之类原文自证或明显误字可证同人，此时 SAME 并在理由写明）；一侧佚名：只有卷数一致且版本/馆藏同源等证据时 SAME，否则 D。叢書子目与单行本同书同撰者也可 SAME。
5. 朝代不兼容（相差两个以上朝代）或著作领域冲突（如一为琴谱一为族谱）→ C。
6. 「不确定」就给 D，不要勉强给 SAME。

输出：写到指定的 out 文件（JSONL，每对一行）：
{"a":"<id>","b":"<id>","verdict":"SAME|C|E|D","reason":"中文一句话，引著录原文要点，如『甲總目萬曆十六年刻七卷馬中良纂，乙千頃堂蔣景倫撰七卷，撰者不同』"}
每个输入对都必须有一行输出，a/b 原样照抄。写完后用一行 python 校验输出行数＝输入对数。最后回复：总对数、各判定码计数、你最没把握的 3 对。
