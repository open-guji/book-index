# wake-c 第三輪：通名大 Work 窮盡（論語、孟子、大學、中庸、四書、孝經、爾雅）

**做了什麼**：以 CiNii Books OpenSearch(JSON) 對 150 個題名關鍵詞（論語／集解／集註／義疏／徵／古義／古訓……孟子……大學中庸……四書……孝經……爾雅……）按刊年切片（1450–1911，單切片>500 則二分）逐頁收割，得 6,668 條 1912 前候選；題名＋責任者映射到庫內既有 Work（c3_map.py，不新建 Work）；取 NCID .json 詳情（出版項、刊年、備註、所藏館）；強證篩選後按（Work、題名、刊年、書肆集合、卷數、訓點者）聚簇（同簇多 NCID 並為一條，館藏並掛）；對全庫日本刊本 edition 查重；剩餘新建。

**強證口徑**：刊年取出版項「年號N [西曆]」且不被方括號包圍；書肆非方括號推定、非「出版事項は他書による」；年號與西曆互校（c3_group.py START 表）；排除寫本／影印／複製、日人補解增注本、題名非本 Work 本體者（c3_map.ALLOW 白名單）。

**產出**：PR1（前150條）＋PR2（餘39條），台賬 ledger3.tsv／ledger3b.tsv；待核見 TODO3.tsv（疑似庫內已有、書肆組合部分重疊、四書零種、責任者不符等）。

**未盡**：1868–1911 年明治刊本未納入；歸屬不明的衍生書（大全、俗解、國字解、日人考訂標記）見 TODO3；爾雅日本刊本多為註疏零種，僅 0 條可建。

**複核**：自抽 30 條回看 CiNii 書目頁（出版項、刊年、書肆），異質 0；另請獨立複抽。

**流程**：c3_harvest.py → c3_cand.py → c3_detail.py → c3_select.py → c3_group.py → build3.py [--apply --part 1|2]。
