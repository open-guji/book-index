# L0 第十一轮：同丛书重复 Book 余量

2026-11-14，L0 去重车道。账本 `merges.json`：137 组，并掉 137 条 Book。判准脚本见 `tools/cand11.py`。

## 本轮处理的三类
1. **主卷数不同**（第十轮不并的 230 组）。这类组里常混着两种注本，例如道藏輯要的《金碧古文龍虎上經》既有彭好古一卷本，也有王道三卷本。做法是按归一后的卷数把组拆成子组，只在卷数相同的子组内判断，撰人不能相抵。可并 22 组，其余主卷数真不同的不并。
2. **丛书名对不上**（版本项写的是底本，如「民國二十四年景印元大德間刻本」「思賢書局本」）。
   - 一组里至多出现一种非本丛书名的底本描述，且这条不能有独立馆藏，才可并。
   - 有两种不同底本的不并，例如叢書集成初編里的鉛印寶顏堂祕笈本和影印紀錄彙編本、鄧析子五種合帙、景印元明善本叢書。
   - 版本项其实是另一部丛书名（如「潛研堂全書本」）的不并。
3. **同一作品分收不同丛书**。查了丛书条目之间的成员重合：同名同版本的丛书条目都是《總目》按馆藏分立的不同记录，丛书线按 GUJI-526 口径有意分立，并以 related_collections 互链；其下的 Book 是不同馆藏的子目。本轮不并。

## 顺带修正
- 判「馆藏是否丛书共有」时，原用 provenance.source 作为馆藏键。故宫（npm）条目的 source 是固定字串 `metadata.npm_item_id`，不分条，因此改为 source＋索书号。复查第七、八、十轮账本，没有因此误并的。
- 10 条 Book 的 contained_in 里同一丛书挂了两次（文淵閣四庫、適園叢書），已合为一条。
