# L0 第八轮 Book 叢書子目重复（细分第七轮剔除类，2026-11-13）

## 候选
- 第七轮后重跑「同一 Work、同一叢書 Collection、同 volume_index 下两条以上 Book」：5,845 组；剔除故宫善本旧籍、两部敦煌遗书后 2,826 组。
- 这些组第七轮因「版本项冲突」「两条都带馆藏」「题名不同」被剔。细看后多数是同一现象：总目把叢書子目著录两次，一次在叢書条下（带叢書共有的馆藏，版本项写子目本身的刊刻年或「影印某本」），一次在分类里写「某叢書本」。两条是同一版本。

## 判准（新）
- **馆藏是否叢書共有**：统计每个 Collection 内各馆藏条目（总目 item id）出现在几条 Book 上；出现 ≥2 次的是叢書层馆藏。组内至多一条 Book 带「独立馆藏」（只属这一条）才并。
- 版本项写刻年（不以「本」结尾）的那条，馆藏必须全是叢書共有，否则可能是单刻本，不并。
- 版本项以「本」结尾的须是本叢書名（t2s 后比对）或「影印某本」，否则不并。
- 卷数（measure_info）须一致或一侧为空。
- 题名不同的（异体、讹字、详略）只在两侧卷数都有且相同时并。
- 剔除：中华再造善本（各 Book 是不同底本）、說郛／稗海系、题名或卷数带节录／残／存等、抄本稿本类叢書下两侧馆藏机构不相交的。

## 结果
- 剔除：卷数不合 501、叢書名不合 115、說郛稗海 104、节录残存 83、中华再造善本 54、题名不同且卷数不全 39、刻年冲突 30、刻年本有独立馆藏 8、两条独立馆藏 1、抄本稿本馆藏不相交 47。
- 盲检 40 组（20 同题、20 异题）：40 SAME。
- 并 1,837 组 1,851 条（`r8/mergebook.py`，列表字段取并集；被并方版本项与 keeper 不同的记入 keeper ai_note）。promotions 改指 778 个文件；草稿库 27 条墓碑另 PR 改指。
