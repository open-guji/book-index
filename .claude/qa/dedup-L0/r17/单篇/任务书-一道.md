# 单篇诗文 vs 同题作品对判

输入 jsonl 每行一对同题 Work（A、B），至少一侧是今晚据《全唐詩》《全唐文》《先唐文》建的单篇（subtype poem/article，ai_note 写着出处卷次）。另一侧多是库里早先的作品（志书著录的书、或别的单篇）。

判断是否**同一部作品**（同一篇/同一书）：
- 「同」：确是同一篇/同一书。例：旧库著录《李賀小傳》（李商隱）与全唐文所收李商隱《李賀小傳》；旧库一卷本《廣陵妖亂志》而全唐文所收是其正文全篇。撰人不一致时须有理由说明是同一作品（如旧条无撰人而著录内容吻合）。
- 「異」：不同作品。例：同题不同作者的诗文（《偶書》《寓言》《雜記》这类泛题）；旧库是多卷书而单篇只是同名短文；同作者同题但明显是两首不同的诗（同题组诗中的不同首）。
- 「不定」：拿不准。
- 旧库条若是三卷以上的书，单篇只是一篇文章，一般判「異」，除非能确定单篇就是这书全文。
- 注意撰人后面方括号是人物 id；两边 id 不同而名字相同，可能只是人物重出，不因此判異。
- 不确定倾向不并。

输出 TSV（无表头），每对一行：`A的id<TAB>B的id<TAB>同|異|不定<TAB>一句理由`。每个输入行都要有输出。只读，不改仓库文件。
