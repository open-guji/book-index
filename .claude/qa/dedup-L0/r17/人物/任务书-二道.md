# 人物同名对判（第二道，独立盲审）

你会拿到一个 jsonl 文件，每行有 pair:[A的id, B的id]（另有摘要字段，可参考，但**必须自己开库原档核实**）。
库在 /home/user/book-index（只读）：人物档 `Entity/<c1>/<c2>/<c3>/<id>-<名>.json`，c1c2c3 就是 id 的末三个字符按原顺序（例如 hixio57ui1ro → Entity/1/r/o/…；不确定就 `ls Entity/*/*/*/<id>-*`）。作品档在 `Work/` 同样分片；某人的作品可 `grep -rl '"entity_id": "<id>"' Work/ | head` 找（慢，必要时才用；摘要字段里有作品题名可参考）。

任务：逐对独立判断是否同一人。口径（用户定，严格执行）：
- **同名、同代（或相邻且生平衔接）、并有佐证**，三者都有才判「同」。
- 佐证：两边挂同一篇/同一组作品、官职籍贯生卒事迹对得上、作品内容与对方身份吻合、可靠史学知识确认。
- 一侧朝代为空：只有作品或简介能钉到同一人才判同；只靠名字不判同。常见名尤其要具体佐证。
- 朝代冲突判「異」；拿不准判「不定」。不确定倾向不并。

输出：TSV，无表头，每对一行，4 列：`A的id<TAB>B的id<TAB>同|異|不定<TAB>一句理由（写出你在原档里看到的具体佐证）`。每个输入行都必须有一行输出。不改任何仓库文件，只写指定的输出文件。
