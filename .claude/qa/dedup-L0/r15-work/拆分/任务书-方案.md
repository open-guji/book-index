# 混条 Work 拆分方案：任务书

古籍目录库里有些 Work 是「混条」：一条 Work 的 indexed_by（各书目著录）或所挂 Book 里混进了另一部书（例如辑本混进原书、节本/一卷本混进全书、同题异人之书、另一修次方志），或撰人里混进了别人。上一轮复核者在并条时发现了这些疑似混条。你的任务：逐条核实，并为确属混条的写出**拆分方案**。只读库，不许改任何库文件。

## 输入
`mixed_N.tsv`（每行：Work id、题名、indexed_by 条数、复核者当时写的理由）。理由只是线索，可能不准，有的 id 其实只是被连带列出、本身并不混。
库路径：`/home/user/book-index/Work/<id倒数第3位>/<倒数第2位>/<末位>/<id>-*.json`；Book 用 `grep -l '"work_id": "<id>"' -r /home/user/book-index/Book --include=*.json` 找（会慢，可以先 `git -C /home/user/book-index grep -l '"work_id": "<id>"' -- Book`）。

## 判定
对每条 Work 打开原文，看 indexed_by 每一条（source、title_info、author_info、summary）、authors、所挂 Book（edition、measure_info、contained_in）。
- 若各条著录与 Book 都是同一部书（同撰人、卷数相合或可解释、同一书系），判「不混」。
- 若确有不同书混入，按「书」分组：每组列出属于它的 indexed_by 条目（用 source＋title_info 原文标识）和 Book id。原 Work 留下与其题名、撰人最相符的那组（stay=true）；其余组 stay=false。
- 拆出的组若库里已有同一部书的 Work（同题同撰人同卷系），在 merges 里写 into 那个 Work id；否则新建（不写 merges）。找已有 Work 可用 `git -C /home/user/book-index grep -l '"title": "<题名>"' -- Work`。
- 撰人混入（authors 里混进别的书的撰人或续编者）而著录本身不混的：写在 `author_fixes`，说明该删哪位、依据何在；不要为此拆组。
- 拿不准的（证据不够、分不清某条著录该归哪组）：整条标 `uncertain: true` 并写原因，不要硬拆。宁可不拆，不可拆错。

## 输出
写一个 JSON 到 `plan_N.json`，结构：
```
{"works": {"<wid>": {"title": "...", "mixed": true/false, "uncertain": false,
    "groups": [{"name": "组名（含卷数）", "stay": true, "books": ["<book id>"...], "indexed_by": [{"source": "...", "title_info": "..."}], "note": "依据"}],
    "author_fixes": [{"drop": "撰人名", "why": "..."}],
    "why": "总判断一句"}},
 "merges": [{"from": "<wid>:<组名>", "into": "<已有 Work id>", "why": "..."}]}
```
- `mixed:false` 的条目只写 title、mixed、why。
- 每个 stay=false 的组必须列全它的 indexed_by／books；stay=true 的组也列全。各组合起来必须覆盖原 Work 的全部 indexed_by 和全部 Book，一条不漏、不重。
- indexed_by 的 source／title_info 要与原文逐字一致（脚本按这两项匹配）。
- 辅助脚本放在你自己的子目录里。全部做完回报：混/不混/拿不准各几条，新建组几个、并入已有 Work 的组几个。
