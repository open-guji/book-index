# 单篇诗文 vs 同题作品对判（第二道，独立盲审：须开库原档 /home/user/book-index/Work/<c1>/<c2>/<c3>/<id>-*.json 核实，c1c2c3 为 id 末三字符；作品若需要，可用你的文献知识）

输入 jsonl 每行一对同题 Work（A、B），至少一侧是今晚据《全唐詩》《全唐文》《先唐文》《樂府詩集》《玉臺新詠》等建的单篇（subtype poem/article/fu/ci/qu，ai_note 写着出处卷次，「收於」列出所在总集与卷次）。另一侧多是库里早先的作品（志书著录的书、或别的单篇）。

判断是否**同一部作品**（同一篇/同一书）：
- 「同」：确是同一篇/同一书。例：旧库著录《李賀小傳》（李商隱）与全唐文所收李商隱《李賀小傳》；旧库一卷本《廣陵妖亂志》而全唐文所收是其正文全篇。撰人不一致时须有理由说明是同一作品（如旧条无撰人而著录内容吻合）。
- 「異」：不同作品。例：同题不同作者的诗文（《偶書》《寓言》《雜記》这类泛题）；旧库是多卷书而单篇只是同名短文；同作者同题但明显是两首不同的诗（同题组诗中的不同首）。
- 「不定」：拿不准。
- 旧库条若是三卷以上的书，单篇只是一篇文章，一般判「異」，除非能确定单篇就是这书全文。
- 注意撰人后面方括号是人物 id；两边 id 不同而名字相同，可能只是人物重出，不因此判異。
- 两条都是单篇、出自不同总集（如一条收於樂府詩集、一条收於全唐詩或先唐诗），撰人相同（或一侧无撰人、属同一作者的同题作）且首句（incipit）相同或基本相同：是同一首，判「同」。首句不同即使同题同作者也判「異」（组诗不同首）。没有首句可比时判「不定」。
- 不确定倾向不并。
