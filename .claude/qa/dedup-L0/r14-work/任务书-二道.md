# Work 并条前独立复核：任务书

你是第二道独立复核。下面这些 Work 对，先前有人判过「可能是同一部书」，但不会告诉你他的结论和理由。你要从头独立判断，**合并前每一对都要过你这一关**。错并比漏并代价大得多：一旦并错，就会把两部不同的书混成一条，很难再拆开。

## 输入
目录：`<scratch>/r14/vc/`，每个 `vNN.jsonl` 一行一对，字段如下：
- `pair`、`原判`、`原由`：`原由`是当初为何「存疑」，仅供参考。
- `A`、`B` 两条摘要：題、又題、撰人、卷、著錄、版本、簡介等。

**每一对都要打开库里两条 Work 的原文核一下**，路径为 `/home/user/book-index/Work/<id倒数第3位>/<倒数第2位>/<末位>/<id>-*.json`，例如 d59f2nkpykn4 → `Work/k/n/4/d59f2nkpykn4-*.json`。
- 重点看 `indexed_by`（各书目原文）、`authors`、`ai_note`。
- 判断每一条是不是「混条」：一条里混进了另一部书或另一个人的著录。

只读库，**不许改任何库文件**。

## 判「同」须同时满足
1. 题名指的是同一部书：异体、繁简、冠名（佛說／欽定／新刻／國朝）、简称与全称、明显误字都算同一题名。
2. 撰人一致：同一人（含异写、字号）或一侧缺；官修书署名不同可以算一致；叢書编者被误填成撰人也可以。
3. 朝代相容。
4. 卷数相容：相同、一侧缺，或差异可解释（附卷、目录卷、合计相等）。
5. 两条都不是混条。是混条的，判「疑」，理由写「混条须先拆」。

## 一律不判「同」
- 节本、摘抄本、选本（如说郛本、一卷选本）对全书。
- 辑本对原书，以及不同辑者的辑本之间。
- 方志的不同修次，以及无名氏方志条对具名方志条。
- 族谱缺纂修人或缺年份、无法证同。
- 佛典一侧无译者，而该经有异译本。
- 通名，如詩集、文集、尚書。
- 稿本／抄本「不分卷」对刻本有卷、且无互证。
- 卷数不合又说不出理由。

拿不准就判「疑」。

## 输出
- 每个 vNN 写一个 TSV 到 `<scratch>/r14/vout/vNN.tsv`，不要表头。
- 每对一行，5 列，用制表符分隔：`A的id	B的id	判定(同/异/疑)	把握(高/中/低)	理由(≤60字)`。
- 每一对都要有一行。
- 自己的辅助脚本放在你自己新建的子目录里，不要放在共用目录的根上。
- 全部做完后，回报每个文件「同／异／疑」的计数。
