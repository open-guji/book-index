# 作品（Work）存疑对逐对复核：任务书

你在给古籍目录库做「同一部书」判定。以前机械判过、标成「存疑」没并的 Work 对，现在要逐对重新看一遍。

## 输入
目录 `<scratch>/r14/chunks/` 下的 `cNN.jsonl`，每行一对。字段如下：
- `pair`：[A 的 id, B 的 id]。
- `原判`：来源批次和标签。
- `原由`：当时为什么存疑。
- `A`、`B`：两条 Work 的要点：
  - 題、又題、撰人（括号里是朝代）
  - 卷、年代、存佚
  - 著錄：书目著录原文摘要，也包括版本与馆藏汇总
  - Book數、版本（版本项｜卷数）、簡介

需要时可以只读查看库：`/home/user/book-index/Work/<id 倒数第3位>/<倒数第2位>/<末位>/<id>-*.json`。**不许改任何文件**，只写下面规定的输出。

## 口径（目录库既定，严格遵守）
判「同」要同时满足以下四条：
1. **题名是同一部书**：异体字、繁简、「佛說」「欽定」「新刊」之类冠名、「國朝」字样、书名简称或全称、明显误字都算同。
2. **撰人一致**：同一人（异写、字号、谥号也算），或一侧没有撰人、另一侧只有一人。官修书署名不同（总裁与纂修）也可以算同。
3. **朝代相容**。
4. **卷数相容**：相同、一侧缺，或差异有合理解释（附卷、目录卷、残存）。

下面几类一律不判「同」：
- 节本、摘抄本、选本、残卷与全书：分立，判「异」或「疑」，不判「同」。
- 同题不同修次的方志：不同纂修者或不同年代就判「异」；无名氏方志条与具名条无法证同，判「疑」。
- 族谱：同姓同地望、同纂修人、同修次才算同；只有题名同、修纂人或年代不同的判「异」。纂修人或年代缺失、无法证同的判「疑」。
- 佛典同题异译：译者不同判「异」；一侧无译者且该经有多个译本的判「疑」。
- 题名是通名（如「詩集」「文集」「年譜」「尚書」「家訓」）、又缺撰人的，判「疑」。
- 拿不准就判「疑」。宁可漏并，不可错并。

「高」把握只给证据充分的「同」：题名专指，撰人同一或一侧缺，卷数吻合或可解释，没有异本的迹象。其余的「同」给「中」。

## 输出
每个 chunk 写一个同名 TSV 到 `<scratch>/r14/out/cNN.tsv`，不要表头。每对一行，共 5 列，用制表符分隔：

`A的id	B的id	判定(同/异/疑)	把握(高/中/低)	理由(≤60字，写关键证据)`

要求：
- chunk 里的每一对都要有一行，不能漏。
- 一个 chunk 写完再做下一个。
- 全部做完后，回报每个 chunk 的「同·高／同·中／异／疑」计数。
