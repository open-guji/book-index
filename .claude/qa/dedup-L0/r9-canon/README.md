# L0 第九轮（一）版本项误拼藏经刻印信息（2026-11-13）

## 现象
- 2,264 条 Book 的 edition 是两段拼接，其中一段是与本书无关的藏经刻印项，如「元至元間杭州路餘杭大普寧寺刻;民國三十七年刻」「清光緒二十三年刻;宋元間磧砂延聖院刻」「宋大觀三年福州東禪等覺院刻;影印明崇禎間刻本」。涉及普寧藏、磧砂藏、崇寧藏（東禪等覺院）、管主八刻本等。
- 同时串入的：publication_info「刊刻者／影印者：（某寺院）」1,242 条；dating 年份取了藏经刻年（如 1264、1085），1,212 条年代错；ai_note 写成「後印／補刻：";民國三十七年刻"」，把真版本当成后印。
- 来源是总目录入时（E／F／G 道，2026-10）串入，具体机制未查。

## 判定
- 只改「不在任何藏经 Collection 内、且 edition 拼有藏经刻印段和另一段」的 Book。藏经 Collection 内的条目，以及 edition 只有藏经刻印一段的（如《大唐西域記》磧砂藏本）不动。
- 藏经刻印段：含 普寧寺、磧砂延聖、東禪等覺院、開元禪寺、福州開元寺、圓覺禪院、資福禪寺、管主八。

## 改法（`fix.py`）
- edition 删去藏经刻印段。
- publication_info 删去含寺院名的子句，删空就去掉字段（1,242 条）。
- dating 若来自目录（source=catalog）且起年早于 1370、而剩下的版本项不是宋元本：按剩下版本项的年号重算（明清民国年号表），得年 927、得区间 28；算不出的（如「影印紀錄彙編本」）去掉 dating（257）。
- edition_type 按剩下版本项重判，45 条改（如影印本、鉛印本、油印本）。
- ai_note 去掉错的「後印／補刻」句，记一行改正说明。
- 文件名里仍带旧版本项（读者按 id 前缀找档，不影响），未改名。

明细：`changes.tsv`。
