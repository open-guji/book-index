单元说明：ai-team `domain/目录与资源/设计/2026-10-正式库全面去重方案/细拆-20261026/README.md`。基线 book-index main `ba18f194a7` 的 754 组；10-26 在最新 main 重算仍 754 组、7,283 对。子目-乙判定表（子目-乙-并在跑）里的 3 对跳过。

## 判据（`judge_zi.py`，逐对）
- **A**：有效撰人相同（`authors`＋总目 author_info 解析，含括注本名；叢書部/獨撰類子目无撰人时继承所属 Collection 撰人＝4a-α 口径），朝代兼容，卷数不矛盾。
- **B**：①一侧缺撰人，另一侧（单书）总目著录的版本表列出该叢書本（取叢書题名最长前缀「P本」，前一字须为分隔；P 之后接「續／補／外／再／後」的不算，防正编续编混连）；②单书 Work 已挂同名叢書的 Book；③两侧都是子目、缺撰人，两叢書同名或同出一系（子目-乙家族表＋寶顏堂各刻、平津館／新斠、文淵閣／薈要）；④撰人一侧多出别号或注校者（人读 94 簇核过，剔混记录 10 条，见 `MIX`）。
- **C**：撰人异姓且两侧责任方式都是撰／著（无辑注校编），或撰人不同且朝代不同。
- **D**：卷数不合；撰人同姓异名；一侧为辑／注／校／编层次；泛称题名缺撰人；缺撰人同题而无上述证据；敦煌；混记录。
- `cluster.py` 按 A／B 边连簇，簇内若有非中性的 C／D 对（辑佚正续编、注本层次、卷数不合等）整簇不并（27 簇）。
