## 口径
- 并：同一责任者（同 entity，或同名同朝）＋题名为异写／省称／全称／冠撰人名、年号、室名、「欽定」「敕修」等＋卷数相合（或一侧缺、或差 1 卷）＋性质相同。合著增减（多校者、附录作者、同修者）不碍。
- C：辑佚本对原书（王仁俊、黄奭、马国翰、汤球等清人辑本对史志著录原书）；节本／摘抄／单篇／论赞对全书；续编、补编、注本、校勘记、评点对原书；同一作者两部书；朝代不兼容。
- D：题名相近而非异体、卷数差大而无法定是否节本、合刻题名与单种、记录本身混杂（须先拆）等。
