来源：`混了同名人的Entity-待拆分清单.md`（2.2 补挂复核 10-25 顺带发现）。
口径：用户 11-02 定「有确定证据就做，查不到就搁置」。证据只取库内 Work 著录（四庫提要「某某字…，某地人」、千頃堂只收明人、版本刊年早于/晚于该 Entity 生卒、著录责任者名与 Entity 名不符等）；联网检索未得结果，不凭印象。
