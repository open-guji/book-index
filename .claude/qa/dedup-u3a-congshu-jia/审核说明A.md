# 子部作品首位责任者·逐名复核说明（U3-a 轨 A）

背景：古籍书目库 book-index（本地 /home/user/book-index，只读，不要改任何文件）里，子部（医、释、道、术数、农、天文算法、谱录、杂家、小说、西学译著等）的作品（Work）首位责任者只有名字、没挂人物 Entity。这些名字在库里撞上了已有人物 Entity。判断：作者位上的人是不是那个 Entity（同一历史人物）。口径「宁缺毋滥」：拿不准就不挂，挂错比漏挂代价大得多。

## 输入
jsonl 包，每行一个名字：
- `cands`：候选人物 Entity（eid、主名 name、命中方式 how［主名／别名:字或號…／…(去釋)］、rel［same 朝代相合／adj 相邻／unk 未知］、dyn、dates 生卒、np 籍贯、alt 别名、note 摘要、uris、nworks 已挂作品数、works 已挂作品「题名｜分类｜朝代」）。
- `works`：本名下待补挂的 Work（最多列 6 个，more 为未列出数量）：k＝Work id，title，role，dyn（著录朝代），sec（分类），ai（author_info 原文），sum（版本摘要），uri。

## 怎么判
- **SAME**：身份吻合、无反证。著名人物（如鳩摩羅什、玄奘、義淨、孫思邈）的译著／本人著作；候选已挂作品与这些 Work 同领域、同时代；佛经译者（釋某）挂其译经；医家挂其医书。
- **DIFF**：有明确反证：年代不容；候选是另一领域人物；别名撞名而姓不同；候选 note 说明是另一人。
- **UNSURE**：证据不足。常见名（两字常见名）而候选作品与此处领域迥异；候选信息太少；字号撞名无正面证据。
- 子部特例：西学译著的外国人名（傅蘭雅、丁韙良等）若候选就是同一外国人（作品皆译著、清末）→ SAME；僧人（釋某）与去釋后的俗名候选，只有候选 note／作品显示是该僧才 SAME。
- 多候选：只能挑一个，且有正面证据；否则 UNSURE。
- 别名命中必须姓同、朝代相合、有正面证据。
- 同一名字下部分 Work 不合，可把不合的 Work id 列进 `exclude`；大半不合则整体 UNSURE。more>0 时未列出的会按整名判断一并挂上；若只有列出的可靠，判 UNSURE。
- 需要更多信息时，可读库里文件：Entity 在 `/home/user/book-index/Entity/<id末位>/<倒数第二位>/<倒数第三位>/<id>-*.json`，Work 同理在 `Work/` 下。不要扫全库。

## 输出
写 jsonl 文件（路径见任务），每名一行，不得遗漏，**每判 10 个名字就追加写一次**（防中断）：
`{"name": 名, "verdict": "SAME"|"DIFF"|"UNSURE", "eid": SAME 时必填, "exclude": [不挂的 Work id], "reason": "一句中文理由（SAME 也要写依据）"}`
不要写到别的路径。最后回报：总名数、SAME／DIFF／UNSURE 各多少，最没把握的 3 个 SAME。

## 第二审（盲复核）附加
若任务写明「第二审」：你是独立复核，从严掌握。候选已挂作品太少（≤1 部）或与待挂 Work 领域不同、又无 uri 一致／别名直接命中／名人确证时，判 UNSURE。名人身份凭记忆者须你确有把握。输出路径同上规则。
