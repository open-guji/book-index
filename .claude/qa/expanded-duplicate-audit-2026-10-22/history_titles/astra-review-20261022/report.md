### H-A001：晁瑮《清豐縣志》是嘉靖《新修清豐縣志》的省题

重新读取 main 两份原档：`d59f6ep8j2ti`、`d59f2njb2wao`。前者原始《千頃堂書目》引文只有晁瑮和省题，虽另有十六卷字段，不能把生成 description 当独立出处。后者《中國古籍總目》明确著录嘉靖新修清豐縣志十六卷、李汝寬修、晁瑮纂，并记嘉靖三十七年刊本；故宫来源 description 也记同年和馆藏号平圖007188–007191。

本轮实际打开[《千頃堂書目》卷六原典转录](https://hhl.cnkgraph.com/Book/742/KR2n0010_006)，第16a叶 `WYG0676-0148a.png` 明列晁瑮清豐縣志十六卷；下条周萬金内黄县志后的「俱嘉靖間修」提供共同修纂时代。网页链接书影请求超时，因此只称核读原典转录，不称目验刻本。原生总目与新取原典在县域、同一纂者、十六卷和嘉靖时代同时相合，足以将本案由候选提升为同书省题。国图0584公共元资料只取得检索摘要，列李汝寬、晁瑮纂修，未作为决定性证据。

这里不是把所有「新修」删掉来合书。清代楊燝、高俊的同题县志明确不在本组。故宫条的四册是装订单位，与十六卷不矛盾；不能由四册造出四卷异书。

建议保留 `d59f2njb2wao`，重复成员 `d59f6ep8j2ti`，但 keeper 方向未经过全引用和正文资产审查。执行前必须保留李汝寬修／晁瑮纂的责任层次，先查李汝寬的 Person 身份，不凭名字补 ID；保留国图0584及资源分组、所有原引文和旧描述快照。两侧来源同时保留后，旧 description 中「惟一志著录」「赖之以存」不可继续当事实。本轮未扫描全部相关 Book，亦未提出版本合并。

### H-A002：同一原编者不能掩盖明代续修范围

main `d59f2ghntpfm`《續修龍虎山志》为《四庫全書存目叢書》史228的北京图书馆藏明刻本。其原始 summary 和 edition 已明列張國祥、張顯庸续撰，原生 authors 却只留元明善。这是具体的责任层次缺漏。

[识典卷上检索结果](https://www.shidianguji.com/zh/mid-page/7520740202857332782)与[法兰西学院馆目检索结果](https://omnia.college-de-france.fr/discovery/fulldisplay/alma990003581050107166/33CDF_INST%3A33CDF_INST)均支持張國祥、張顯庸的明代续修责任，但完整网页未成功获取，明确只作线索。另一总目检索摘要同时出现三卷续编一卷与六卷，提示下轮须逐本核卷，不能据摘要擅自统一卷数。

本案也不能简单升级 separate：四库所见明续修本与存目所收明刻本可能存在相同部分，而目前另一 Work 已混挂元本。应先取得存目史228明刻本的卷首、序跋、三卷目录，再和元刻本及周召续编逐项对照，把 Book、来源与 resources 映射到各修订层。范围未清之前既不整组合并，也不把所有来源强行分成两部完全无关的书。
