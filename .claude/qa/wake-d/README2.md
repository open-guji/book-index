# wake-d 第二輪：補庫內缺的日本版本（新建線）

對 shard3（113 個 Work）查 NDL Search／CiNii Books，庫內該 Work 下缺的 1912 前日本刊本新建 Book，並掛可確認的日本館藏。

- 新建 19 個 Book（機器號 wake-d＝1939）：標題徐狀元補注蒙求 6（天和2、寛保元、明和4、寛政2、寛政4、天保3）、名醫類案 2、孫子詳解、魏武帝註孫子、和名類聚抄、傷寒明理論、經穴彙解、大戴禮記補注、金銀圖錄、五行大義、顱顖經、論語集解義疏（寛延3）、和漢茶誌。
- 台賬 `ledger2.tsv`；未建候選與原因 `TODO2.tsv`；腳本 `build2.py`。
- 查重：對 origin/main 按 Work 下既有 Book 的題名＋刊年＋刊者逐一核對；與既有條相近者在 `ai_note` 互記（孫子詳解文久元年學半樓本、大戴禮記補注文化三年本、論語義疏寛政七年/元治補刻本等），不硬並。
- 口徑：刊者、刊年、卷冊、所藏館與索書號只錄 NDL／CiNii 頁面確認者；只憑序年或書肆項不合者不建；1912 後印本不建。早稻田藏本無索書號，僅記 NDL 與古典籍總合DB 連結。
