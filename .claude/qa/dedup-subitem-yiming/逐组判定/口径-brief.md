# 任务：判定同题 Work 组里哪些条是同一部书（古籍目录去重，經部）

你会拿到一个人读稿 review-XX.md，里面每个「## 组」是题名归一后相同的若干条 Work（作品层记录）。每条列出：id、题名、責任者（朝代+姓名+角色）、是單行本还是某叢書的子目（括注叢書撰者=该叢書署名的撰者）、著錄（title_info｜author_info｜分类｜摘要），最多 3 条著錄。

请逐组判定：组内哪些条是**同一部作品**（应合并成一条 Work），哪些是不同作品。只读这个文件即可，不要改任何仓库文件。

## 口径（严格，宁缺毋滥）
同一部作品 = 同一撰者（或同一辑者、同一注者）写的同一部书，不同版本/不同丛书收录的都算一部。判「同」需要满足：
1. 撰人能对上：同名（允许异体字、避讳改字如 陳宏謀=陳弘謀、玄/元、胤/允；字号与本名如 江藩=節甫老人、釋南潛=董說）；或一侧子目无撰人，但它在「叢書部/獨撰類」，所属叢書撰者与另一侧撰人同名（獨撰类子目不题撰人，是著录省略）；或一侧子目 author_info 只列原书撰者/注者（如「漢戴德傳」），而所属叢書撰者正是另一侧的撰人（如 函海 李調元 → 李調元《夏小正箋》）。
2. 卷数不矛盾：相同、一侧缺、差一（含首一卷/附录有无），或可解释（不分卷≈一卷）。卷数悬殊（如八卷对一卷）默认不同，除非显然是节本以外的同书分卷差异——拿不准就判存疑。
3. 朝代兼容；领域不冲突。
4. 摘要里互见（如单行本的版本列「XX叢書本」，另一侧正是该叢書子目）是强证据。

一定不同（分立 C）：
- 撰人不同的同名书（各家《易說》《中庸》《論語注》等泛称题名，绝大多数是异书）。
- 同一原书的不同注本/不同层次：如 何晏集解 vs 朱熹集注；经文白文本 vs 某家注本；原书 vs 补/疏/校/考。
- **纬书/辑佚书的不同辑者**：孫瑴（古微書，墨海金壺/守山閣/叢書集成初編多为此本）、喬松年（緯攟，喬勤恪公全集/山右叢書）、黃奭（漢學堂/黃氏逸書考）、馬國翰（玉函山房輯佚書）、殷元正、趙在翰、劉學寵、說郛本——不同辑者互为分立；同一辑者的才是同书。
- 节钞本对全本、批点本对原本。

存疑 D：证据不足以判同也不足以判异（例如两侧都无撰人且无源流证据；撰人疑形误但无证；卷数矛盾无法解释）。
- 「一侧或两侧缺撰人」时：仅凭同题同卷**不能**判同，需要上面第 1 条或第 4 条的证据；否则判 D（若撰人/辑者/时代可看出不同就判 C）。
- 敦煌遗书一律 D。

「机判同撰人可并的对」只是提示，你要独立核对，错了就推翻。

## 输出
把结果写成 JSON 文件（路径见下），格式：
```json
[{"g": 组号, "same": [{"ids": ["id1","id2"], "level": "A或B", "why": "依据（中文，一句，写清撰人/丛书/卷数证据）"}],
  "doubt": [{"ids": ["idX","idY"], "why": "存疑理由"}],
  "distinct_why": "组内其余各条之间为何不同（一句，如：各家同名異書，撰人不同）"}]
```
- same：每个簇是一部书，ids ≥2 条；level A=撰人直接同名且卷数相合，B=要靠继承丛书撰者、互见、异写等证据。没有就给空数组。
- doubt：拿不准的成对（或成簇）关系；没有就空数组。不在 same/doubt 里的条，默认彼此分立。
- 每个组都要有一项，组号照稿里的数字。
最后用两三行汇报：组数、same 簇数、doubt 数，以及你觉得最没把握的 3 个判定。
