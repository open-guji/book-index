# 新-子目异名：含叢書子目、叢書異名或對單行本的同題組（第二輪細拆單元）

範圍：ai-team `domain/目录与资源/设计/2026-10-正式库全面去重方案/细拆-20261026/README.md` 的「新-子目异名-經」——`dedup-census.py` 未判同題組中，`subitem_groups.py` 歸為「子目但丛书异名」的經部組。基線 main `a24525e184` 重算仍 568 組、25,487 對；與「子目-乙-并」判定表 `../dedup-subitem-yi/judged-07fc66fc.tsv` 無重疊對。

## 流程
1. 普查 → `subitem_groups.py` → `profile_diff_author.py` → `assign_units_20261026.py`，取本單元行；`../dedup-subitem-yi/feat.py` 抽特徵。
2. `judge.py` 機判每對：A（有效撰人相同、朝代兼容、卷數不矛盾）／C（撰人姓氏全異、或纬書異輯者）／D（一側缺撰人且卷數懸殊）／R（其餘交逐組判）。有效撰人含獨撰類子目繼承叢書撰人（子目-乙判據）。經書本名、一側為漢魏原書撰者／注者、同姓異名、撰人部分重合一律交逐組判。
3. `dump.py 8` 把含 R／A 對的 489 組寫成人讀稿，8 個子 agent 按 `逐组判定/口径-brief.md` 逐組判同簇／存疑，結果在 `逐组判定/verdict-*.json`。
4. `combine.py --accept-conflicts` 匯總：agent 判同而機判 C 的 56 對逐條人工看過（名字異寫：安世平甫＝項安世、朱睦＝朱睦㮮、呉黙＝吳默、熙時子＝劉攽、釋南潛＝董說；敕撰書署名異；單行本馬國翰輯本版本列玉函山房、玲瓏山館二叢書本互見），認可，見 `机判冲突-已人工认可.tsv`。另把卷數懸殊或混記錄的 5 簇降為存疑（孟子師說 二卷／七卷、禮記集說 八十／七十卷、淩堃易林 四卷／二卷、吳汝綸易說混入吳汝惺提要、春秋經傳集解子目只題音義者）。
5. 結果：可並 354 簇（A 58／B 296）被並 480 條，`clusters-a24525e1.json`；簇間分立 C 1,331、存疑 D 1,109 條邊寫入 `../dedup-judged/新-子目异名-經.tsv`（存疑邊全記，分立邊只補連通）。
6. 獨立抽檢（另起子 agent，不看判定理由）：A 10%＋B 30% 共 95 簇，同意 95/95；分立對抽 40，同意 39，1 對（拾雅）改存疑。異質率 1/135＝0.7%，低於 3% 停批線。名單與結論在 `抽检/`。
7. 分兩批實施（每批 ≤300 組）：`mkbatch.py` → `apply_yiming.py --apply` → `fix_my_chains.py --apply`（本批被並者身上的舊墓碑改指新 keeper，並在 keeper `merged_in` 記 via）→ `../dedup-subitem/post.sh <批次目录>`（善後＋門禁）。

## 已知遺留
- 若干單行本 Work 本身混了多個輯者的著錄（緯書馬國翰本混入王仁俊續編本、黃奭本混入玉函本；幾何原本六卷本混入十五卷本等），並條不加重混雜，但記錄本身待「先拆後並」類單元處理，抽檢報告列有 id（`抽检/audit-*.json`）。
- 存疑 1,109 條邊多為一側子目不題撰人、又無互見（龍威祕書、叢書集成初編等），大概率同書但按「寧缺毋濫」不並；若後續補撰人或補版本互見，可從 main 重跑本流程。
