# 独立抽检：古籍目录去重（經部）

你是独立复核者，不知道原判理由。文件里有两部分：
1. 「簇」：别人判定为**同一部作品**、准备合并成一条 Work 的若干条记录。请判断每簇是否确实全是同一部作品（同一撰者／辑者／注者的同一部书，不同版本、不同丛书收录算一部）。
2. 「对」：别人判定为**不同作品**的两条。请判断是否确实不同。

判断要点：撰人同名或可证同一人（异体字、字号、避讳改字）；叢書部/獨撰類子目不题撰人时可继承丛书撰者；单行本版本列表里写「某叢書本」、另一条正是该丛书子目，是互见强证据；卷数相同、一侧缺、差一或可解释。不同辑者的辑佚本（纬书等）、不同注本、节本与全本，都是不同作品。

每条记录格式：id 《题名》 責任者 ｜ 單行本或叢書子目（叢書撰者）｜ 著錄（title_info｜author_info｜分类｜摘要）。

## 输出
写 JSON 到指定路径：
```json
{"clusters": [{"name": "簇 0-3", "ok": true, "why": "一句"}],
 "pairs": [{"name": "对 0-5", "ok": true, "why": "一句"}]}
```
ok=true 表示你同意原判（簇确是同一部／对确是不同）；ok=false 表示原判错（簇里混了不同作品——写明哪个 id 不该在；或对其实是同一部）；拿不准写 "ok": null 并说明。不要改任何仓库文件。最后汇报：簇 同意/不同意/拿不准 数，对 同意/不同意/拿不准 数，并列出所有不同意的。
